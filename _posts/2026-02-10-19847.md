[문제 링크](https://www.acmicpc.net/problem/19847) 
## **풀이**
### 문제 요약
마지막 여우가 받게 되는 신탁 수의 기댓값을 구하세요.
### 접근
기댓값을 구하는 수식을 통해 계산해도 되지만 어떤 신탁의 수보다 더 큰 수가 뒤에 들어오면, 큰 수는 **나머지 연산**에 의해 무시하게 됩니다. 이 원리를 이용하면 좀 더 빠르게 문제를 해결할 수 있습니다.

### 기댓값
**기댓값**은 확률 과정에서 얻을 수 있는 모든 경우의 수의 가중 평균입니다.

$$E[X] = \sum_{i=1}^{n} x_i p_i$$

예를 들어 신탁 수가 6일 경우, $\frac{0+1+2+3+4+5}{2}$의해 2.5라는 값이 나옵니다. 

다른 예로 10, 3, 5가 나올 경우, $\frac{1}{10}$이 3의 나머지 연산만큼 조정되므로 $\frac{1}{10}\times3+\frac{1}{10}\times6=\frac{9}{10}$가 되고, 5의 나머지 연산은 3의 나머지 연산과 동일하므로 무시해도 됩니다. 그러므로 0.9라는 기댓값을 구할 수 있습니다.

### DP
* $dp[x]$: 신탁 값 $x$의 경우의 수

dp를 정의해 놓고 작은 수가 의미가 있으므로 큰 수부터 거꾸로 나눠가며 경우의 수를 구합니다. 더 큰 수의 경우 범위를 벗어나는 구간은 제외해 연산을 더 빠르게 합니다. 

마찬가지로 나머지 연산보단 뺄셈 연산이 더 빠를 수 있습니다.

```python
import sys
def print(*args, sep=" ", end="\n"): return sys.stdout.write(sep.join(map(str, args)) + end)
def input(): return sys.stdin.readline().rstrip()

def main():
    n = int(input())
    x = list(map(int, input().split()))
    now = x[0]
    dp = [1]*now
    for i in range(1, n):
        while now > x[i]:
            dp[now-1-x[i]] += dp[now-1]
            now -= 1
    ans = 0
    for i in range(1, now): ans += i*dp[i]
    print(f'{ans/x[0]:.12f}')
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, now; cin >> n >> now;
    ll tot = now;
    vector<int> dp(now, 1);
    for(int i = 1; i < n; i++){
        int x; cin >> x;
        while(now > x){ 
            dp[now-1-x] += dp[now-1];
            now--;
        }
    }
    ll ans = 0;
    for(int i = 1; i < now; i++) ans += (ll)i*dp[i];
    cout << setprecision(12) << fixed << double(ans) / tot;
    return 0;
}
```
