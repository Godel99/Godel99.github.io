[문제 링크](https://www.acmicpc.net/problem/33602)
## **풀이**
### **문제 요약**
$N$개의 문자열 $S$를 부분 수열[^1]로 가지면서, 금지된 문자열 $T$의 부분 수열을 가지지 않는 문자열을 찾으세요.

[^1]: 주어진 수열에서 0개 이상의 원소를 제거하고, 남은 원소들의 원래 순서를 유지하며 만든 수열

### **그리디**
문자열 $T$의 문자를 무조건 제외하고 생각하면 틀릴 수 있습니다. 왜냐면 $T$의 문자와 $S$의 문자가 동일할 수 있기 때문입니다. $S$의 문자를 가져가면서 $T$의 문자가 모두 포함되지 않도록 $T$의 문자열을 관리하는 식으로 접근해 봅시다.

일단 $S$의 부분 수열 중 $T$의 부분 수열과 완전히 일치를 한다면, $NO$가 정답입니다.

그 외에는 $S$와 $T$가 겹치는 문자를 부분 수열의 **분리점**으로 두고 그 뒤에 $S$의 문자들을 배치해 주는 겁니다. $T$ 다음에 오는 문자는 $S$의 문자이므로 금지된 문자가 늘어나지는 않게 되며, $T$의 문자에 따라 금지된 문자의 길이는 **단조**적으로만 증가합니다. 따라서, 이 과정을 반복하면 **그리디**하게 문제를 해결할 수 있습니다. 

마지막에 $T-1$개의 문자만 배치해주면 $T$의 부분 수열을 모두 포함하지 않기 때문에 문제의 조건을 만족하게 됩니다.

## **구현**

```python
import sys
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n = int(input())
    s = [input() for _ in range(n)]
    t = input()
    ch = [[] for _ in range(len(t))]
    for i in range(n):
        r = 0
        for c in s[i]:
            if c == t[r]:
                r += 1
                if r == len(t): 
                    print('NO') 
                    return 0
            else: ch[r].append(c)
    print('YES')
    for i, tc in enumerate(t):
        for c in ch[i]: print(c, end='')
        if i < len(t)-1: print(tc, end='')
    return 0
if __name__ == '__main__':
    sys.exit(main())
```

        int r = 0;

            if(c == t[r]){
                r++;
                if(r == t.size()){
                    cout << "NO";
                    return 0;
                }
            }
            else ch[r].push_back(c);
        }
    }
    cout << "YES\n";
    for(int i = 0; i < t.size(); i++){
        for(char c : ch[i]) cout << c;
        if(i < t.size()-1) cout << t[i];
    }
    return 0;
}
