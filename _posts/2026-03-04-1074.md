[문제 링크](https://www.acmicpc.net/problem/1074) 
## **풀이**
### **사분면**
2차원 배열을 사분면으로 나눠서 보면 $Z$ 모양의 패턴을 볼 수 있습니다. $Z$ 모양의 방향과 순서와 동일하게 왼쪽 상단, 오른쪽 상단, 왼쪽 하단, 오른쪽 하단 순으로 **사분면의 크기**만큼 더해져 간다는 것을 알 수 있습니다.

### **재귀**
주어진 위치 $r,\ c$ 를 기준으로 사분면의 크기를 **분할**하면서 위치에 올 수를 측정합니다. 분할에는 **재귀**를 쓰면 용이합니다.

1. 왼쪽 상단: 크기 조정 없이 분할만 진행합니다.
2. 오른쪽 상단: 사분면의 크기만큼을 더해주고 분할합니다.
3. 왼쪽 하단: 사분면의 크기 $\times$ 2 만큼을 더해주고 분할합니다.
4. 오른짝 하단: 사분면의 크기 $\times$ 3만큼을 더해주고 분할합니다.

## **구현**

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n, r, c = map(int, input().split())
    def solved(n, r, c):
        if n == 0: return 0
        h = 1<<(n-1)
        size = h*h
        if r < h and c < h: return solved(n-1, r, c)
        elif r < h and c >= h: return size+solved(n-1, r, c-h)
        elif r >= h and c < h: return 2*size+solved(n-1, r-h, c)
        else: return 3*size+solved(n-1, r-h, c-h)
    print(solved(n, r, c))
    return 0
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int solved(int n, int r, int c){
    if(n == 0) return 0;
    int h = 1<<(n-1);
    int size = h*h;
    if(r < h && c < h) return solved(n-1, r, c);
    else if(r < h && c >= h) return size+solved(n-1, r, c-h);
    else if(r >= h && c < h) return 2*size+solved(n-1, r-h, c);
    else return 3*size+solved(n-1, r-h, c-h);
}

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, r, c; cin >> n >> r >> c;
    cout << solved(n, r, c);
    return 0;
}
```
