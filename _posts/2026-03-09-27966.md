## **풀이**
### **트리 설계**
<p align="center"/><img src="/assets/img/posts/27966.png" alt="별 모양 트리" width="500">

두 정점 사이의 거리의 합이 최소가 되는 트리를 설계해야 합니다. 두 정점 사이의 거리가 최소가 되게 트리를 설계하려면 **별 모양** 트리가 가장 알맞다는 것을 알 수 있습니다.

한 점을 중심으로 모든 정점이 연결된 별 모양 트리라면, **거리가 1, 2인** 정점만 존재하게 되므로 거리의 합이 최소가 된다는 것을 알 수 있습니다.

그렇다면 거리가 1, 2인 쌍의 개수만 구해주면 최소의 합을 구할 수 있습니다. 이를 식으로 표현하면, 거리가 1인 쌍은 한 점을 중심으로 나머지 정점이 연결되는 구조이므로 $(N-1)$개라는 것을 알 수 있습니다. 거리가 2인 쌍은 하나의 간선을 이루기 위해선 정점 3개가 필요합니다. 따라서 거리가 2인 쌍은 $\frac{(N-1)(N-2)}{2}$개입니다. 거리의 합을 구해야 하므로, $(N-1)\times1+\frac{(N-1)(N-2)}{2}\times2=(N-1)^2$가 최종 거리의 합이 됩니다.

## **구현**
<details markdown="1">
<summary>코드</summary>

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n = int(input())
    print((n-1)*(n-1))
    for i in range(2, n+1): print(1, i)
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>

}
```
