[문제 링크](https://www.acmicpc.net/problem/26074) 
## **풀이**
### **따라쟁이**
만약 후공 입장에서 이기고 있고 후공은 선공이 두는 곳에 **대칭**적으로 그대로 따라 둔다면 결국 후공이 필승입니다.

### **대칭**
선공 입장에서는 먼저 둠으로써 이기는 상황을 먼저 가져갈 수 있고, 이 상태에서 대칭성만 유지한다면 선공이 후공의 필승 입장이 될 수 있어서 선공이 무조건 필승입니다. 대칭성을 유지하기 가장 좋은 방법은 처음부터 **중앙**에 두는 것입니다. 중앙에 어떤 블록을 두던지 대칭성만 확보한다면 선공이 필승인 전략입니다.

하지만 문제는 **게임판의 크기**에 따라 대칭성을 확보할 수 있느냐 없느냐가 결정된다는 것입니다.

### **예외**
예를 들어, $1\times 2\ or\ 2\times 1$ 게임판의 경우에서만 유일하게 선공이 $1\times 1$ 블록을 둘 수밖에 없고 대칭성을 유지하는 게 불가능합니다. 따라서,  $1\times 2\ or\ 2\times 1$ 게임판의 경우 후공이 무조건 필승이므로 이 경우만 따로 예외 처리해 주면 됩니다.

## **구현**
<details markdown="1">
<summary>코드</summary>

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n, m = map(int, input().split())
    print('ChongChong' if n == 1 and m == 2 or n == 2 and m == 1 else 'GomGom')
if __name__ == '__main__':
    main()
```
