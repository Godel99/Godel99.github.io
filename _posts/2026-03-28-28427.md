[문제 링크](https://www.acmicpc.net/problem/28427) 
## **풀이**
모든 $x,\ y$의 쌍에 대해 등차수열의 합을 구하고, 그 합이 소수인지 매번 판별하면 시간 초과 우려가 있습니다. 문제 제목에서 유추할 수 있듯이 숨겨진 트릭(trick)을 찾아내야 합니다.

### **수학적 접근**
$x$부터 $y$까지의 등차수열의 합의 공식은 아래와 같습니다.

$$S = \frac{(x+y)(y-x+1)}{2}$$

이 합이 소수 $p$가 되어야 하므로 다음과 같이 나타낼 수 있습니다.

$$(x+y)(y-x+1) = 2p$$

여기서 $A=(x+y)$, $B=(y-x+1)$라고 한다면 조건에서 $x<y$이고 $y-x \geq 1$이므로, $B \geq 2$입니다.

한 가지 더 $A - B = (x+y) - (y-x+1) = 2x - 1$입니다. 문제에서 $L \geq 2$이므로 $x \geq 2$이고, $2x-1 > 0$입니다. 즉, 항상 $A > B$가 성립합니다.

결국 $A > B \geq 2$인 두 정수의 곱이 소수의 2배인 $2p$와 같아야 합니다. $p$가 소수이므로, 조건을 만족하는 곱셈 조합은 작은 수 $B = 2$, 큰 수 $A = p$뿐입니다. 

$B = 2$으로부터 $B = y - x + 1 = 2 \Rightarrow \mathrm{y = x + 1}$라는 사실을 알 수 있습니다. 즉, **$x$와 $y$가 반드시 연속된 두 정수**여야 합니다. 덕분에 모든 쌍 $(x,\ y)$를 굳이 다 구할 필요가 없이 $x$에만 집중할 수 있게 됐습니다. 이때 합은 $A = x + y = 2x + 1$이 되며, 이 값이 소수 $p$가 되어야 합니다.

결과적으로 **$[L, R-1]$ 범위 내의 정수 $x$ 중에서, $2x+1$이 소수인 $x$의 개수를 구하시오.** 로 문제가 단순해집니다.

### **에라토스테네스의 체**
$2x+1$이 소수인지 판별하기 위해 $1,000,000$ 범위 내에 소수를 에라토스테네스의 체 알고리즘을 이용해 미리 구해줍니다.

### **누적합**
에라토스테네스의 체 이용해서 소수를 판별할 수 있게 됐으니, 그 개수를 구하기 위해 누적합을 이용해 줍니다. 역시 누적합을 쓰기 위해선 배열 $p[i]$를 만들어 줍니다. $2i+1$이 소수라면 $p[i]=p[i-1]+1$이고 아니라면, $p[i]=p[i-1]$로 누적해 가는 겁니다.

질의는 범위 $[L, R]$에서 $p[R-1]-p[L-1]$를 간단히 구해주면 됩니다.

## **구현**

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

from math import sqrt

def main():
    maxR, maxX = 1_000_001, 500_000
    p = [1]*(maxR+1); p[0] = p[1] = 0
    for i in range(2, int(sqrt(maxR))+1):
        if p[i]: p[i*i:maxR+1:i] = [0]*len(range(i*i, maxR+1, i))
    ps = [0]*(maxX+1)
    for x in range(1, maxX+1):
        if p[2*x+1]: ps[x] = ps[x-1]+1
        else: ps[x] = ps[x-1]
    q = int(input())
    ans = []
    for _ in range(q):
        L, R = map(int, input().split())
        ans.append(str(ps[R-1]-ps[L-1]))
    print('\n'.join(ans))
    return
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int maxR = 1'000'001, maxX = 500'000;
    vector<bool> p(maxR+1, 1); p[0] = p[1] = 0;
    for(int i = 2; i*i <= maxR; i++){
        if(p[i]) for(int j = i*i; j <= maxR; j += i) p[j] = 0;
    }
    vector<int> ps(maxX+1, 0);
    for(int x = 1; x <= maxX; x++){
        if(p[2*x+1]) ps[x] = ps[x-1]+1;
        else ps[x] = ps[x-1];
    }
    int q; cin >> q;
    while(q--){
        int L, R; cin >> L >> R;
        cout << ps[R-1]-ps[L-1] << '\n';
    }
    return 0;
}
```
