[문제 링크](https://www.acmicpc.net/problem/32105) 
## **풀이**
$N$이하의 양의 정수의 합이 두 소수의 곱이 되는 **쌍의 최대 개수**를 구해야 합니다. 두 양의 정수는 겹치지 않아야 합니다.

### **수학적 강 귀납법**
$N$개의 정수를 두 개씩 쌍으로 묶어야 하므로 가능한 최댓값은 $\lfloor {N \over 2} \rfloor$입니다. 그렇다면 $1$부터 $N$까지 두 개씩 묶은 합이 두 소수의 곱으로 나타낼 수 있는 쌍의 개수를 $\lfloor {N \over 2} \rfloor$라고 귀납적으로 증명한다면, 이러한 **증명 방식**이 쌍의 최대 개수를 **그리디**하게 유지합니다. 일반 귀납법의 경우 $1$을 기본 상태로 두고 임의의 $k$가 참이라 가정 후, $k+1$도 참인 것을 증명합니다. 그보다 $1,\ 2,\ 3,\ldots,\ k$까지 모두 참이라고 가정 후, $k+1$이 참인 것을 증명하는 것을 강 귀납법이라고 합니다. 강 귀납법을 이용해 이 문제를 접근해 봅니다.

보통 $1,\ 2,\ 3,\ldots,\ k$까지를 참으로 가정하지만, 거꾸로 구간 $(L,\ N)$에서 역으로 $N$부터 임의의 수 $L$까지의 참이라고 가정해 봅니다. 

일단 구간 $(L,\ N)$의 개수가 **짝수**일 경우, 구하고자 하는 것은 두 개의 쌍의 합이 두 소수의 곱으로 나타낼 수 있어야 합니다. 예를 들어, $N=10,\ L=5$이라 한다면 $1,\ 2,\ldots,\ 10$의 개수는 짝수이고 $5+10=15\rightarrow3\times5$로 3과 5라는 두 소수의 곱으로 나타낼 수 있습니다. 그럼 $5,\ 6,\ldots,\ 10$에서 왼쪽 끝과 오른쪽 끝을 묶어 쌍으로 가운데로 좁혀가면, $5+10=6+9=7+8=15$와 같이 **홀수+짝수=홀수**가 **일정**해야 최대한 많은 쌍을 얻을 수 있다는 것을 알 수 있습니다. 즉, $L+N$가 홀수가 되어야 하며, 이는 두 소수의 곱도 홀수라는 말이 됩니다. 소수 중 짝수는 2말고는 없으니 일단 2는 제외해 줍니다. $L+N$을 두 홀수 소수의 곱으로 나타내야 하는데, 두 홀수 소수 중 하나를 **$3$** 둬야 합니다. 왜냐면 $L+N=5p$같이 3보다 더 큰 소수를 가정하면, $L$의 범위가 $N$보다 커지거나 $1$보다 작아질 수 있습니다. 결국 가장 많은 쌍을 찾아내고 가장 안전하게 구간을 묶어낼 수 있는 홀수 소수는 **$3$** 이 됩니다. 이로써 구간의 개수가 짝수일 때, $L+N=3p$로 나타내며 최대 $\lfloor {N \over 2} \rfloor$를 만족하게 됩니다.

구간 $(L,\ N)$의 개수가 홀수의 경우는 $N-1$를 해주면 짝수가 되며, 이미 짝수에 대해서 성립함을 보였으므로 **홀수**도 귀납법에 의해 자명하게 성립함을 알 수 있습니다. 그럼 $N$부터 $L$까지 강 귀납법으로 거꾸로 증명해 가고, 다시 $L-1$부터 $1$ 구간도 증명을 반복해 가면 구하고자 하는 $\lfloor {N \over 2} \rfloor$에 도달할 수 있습니다. 여기서 범위 $N \le 7$의 기본 상태는 손으로 직접 증명을 해 줍니다.

### **베르트랑 공준**
두 홀수 소수의 범위는 $\lfloor {N+3} \rfloor \lt 3p \lt \lceil {2N+1} \rceil$입니다. 두 소수 중 하나를 3이라 했으므로, 하나의 소수에만 집중할 수 있게 됐습니다.

* **베르트랑 공준**: 임의의 정수 $2\leq n$에 대하여, $n \lt p \lt 2n$인 소수 $p$가 항상 존재한다.

베르트랑 공준에 의해 소수 $p$가 항상 존재한다는 사실을 알 수 있습니다. $p$ 범위는 $\lfloor {N+3 \over 3} \rfloor \lt p \lt \lceil {2N+1 \over 3} \rceil$이므로 $L=3p-N$에서 베르트랑 공준에 의해 $3<L\leq N$ 범위의 $L$도 존재함을 알 수 있습니다. 그러므로 베르트랑 공준에 의해 **$L$을 특정**할 수 있게 됩니다. 

한 가지 문제는 베르트랑 공준의 범위가 $\frac{N+3}{3}\times2=\frac{2N+6}{3}$로 $\frac{2N+1}{3}$보다 넓습니다. 다행인 것은 베르트랑 공준은 **최소 소수를 보장**하는 정리이므로, 실제 $7\leq N\leq72$ 범위를 계산해 보면, 충분한 소수가 존재함을 알 수 있고 $N>72$부터는 100% 소수가 존재합니다.

### **중국인의 나머지 정리**
$L$의 값을 특정할 때, $L+N=3p$을 통해 $L+N$이 **3의 배수**이며, 동시에 **짝수**라는 것을 알 수 있습니다.

* **중국인의 나머지 정리**: 어떤 숫자 $x$가 있을 때, $x$를 직접 알지 못해도 **서로소**인 여러 숫자로 나눈 나머지들만 알면 $x$가 무엇인지 정확히 복원할 수 있다는 정리

중국인의 나머지 정리를 이용해 3의 배수이자, 짝수를 동시에 만족하는 수는 6이므로 $L$의 범위를 6씩 좁혀가면 좀 더 빠르게 $L$의 값을 특정할 수 있습니다.

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    N = int(input())
    isp = bytearray([1])*(N+1)
    isp[0] = isp[1] = 0
    for i in range(2, int((N+1)**0.5)+1):
        if isp[i]: isp[i*i:(N+1):i] = bytearray([0])*len(range(i*i, (N+1), i))
    ans = []
    while N > 7:
        flag = 0
        for LL in range(N-1, 0, -1):
            if (LL+N)%3 == 0 and (LL+N)&1:
                for L in range(LL, 0, -6):
                    if isp[(L+N)//3]:
                        for i in range((N-L+1)//2): ans.append(f'{L+i} {N-i}')
                        N = L-1
                        flag = 1
                        break
            if flag: break
    if N >= 6: ans.extend(('1 5', '2 4', '3 6'))
    elif N >= 4: ans.extend(('1 3', '2 4'))
    elif N == 3: ans.append('1 3')
    print(f'{len(ans)}\n'+'\n'.join(ans))
    return
if __name__ == '__main__':
    main()
```

```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
using pll = pair<ll, ll>;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int N; cin >> N;
    bool isp[N+1]; memset(isp, 1, sizeof(isp));
    isp[0] = isp[1] = 0;
    for(int i = 2; i*i <= N+1; i++){
        if(isp[i]) for(int j = i*i; j <= N+1; j+=i) isp[j] = 0;
    }
    vector<pll> ans; ans.reserve(N/2);
    while(N > 7){
        bool flag = 0;
        for(int LL = N-1; LL > 0; LL--) if((LL+N)%3 == 0 && (LL+N)&1){
            for(int L = LL; L > 0; L -=6) if(isp[(L+N)/3]){
                for(int i = 0; i < (N-L+1)/2; i++) ans.push_back({L+i, N-i});
                N = L-1;
                flag = 1;
                break;
            }
            if(flag) break;
        }
    }
    if(N >= 6) ans.insert(ans.end(), {{1, 5}, {2, 4}, {3, 6}});
    else if(N >= 4) ans.insert(ans.end(), {{1, 3}, {2, 4}});
    else if(N == 3) ans.push_back({1, 3});
    cout << ans.size() << '\n';
    for(auto& [x, y] : ans) cout << x << ' ' << y << '\n';
    return 0;
}
```
