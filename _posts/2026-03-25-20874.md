## **풀이**
### **문제 요약**
이 [문제](https://www.acmicpc.net/problem/27972)를 풀어보면 20874번 문제를 이해하는데 큰 도움이 됩니다.

* 음 하나를 연주해야 할 때마다 $1$부터 양의 정수 $N$까지의 정수 중 하나를 쓴다.
* 직전에 연주한 음이 현재 연주할 음보다 낮으면 직전에 쓴 수보다 큰 수를 쓴다.
* 직전에 연주한 음이 현재 연주할 음보다 높으면 직전에 쓴 수보다 작은 수를 쓴다.
* 직전에 연주한 음과 현재 연주할 음이 같으면 직전에 쓴 수를 쓴다.

위와 같은 조건을 만족하는 음들을 $M$이하의 양의 정수로 표현해야 합니다. 전체 악보가 주워지고 악보의 구간 $[L,\ R]$이 질의로 주어질 때마다, $M$이하의 양의 정수로 음을 표현할 수 있는지를 판별해야 합니다.

### **불가능한 구간**
주어진 $M$의 양의 정수로 구간 $[L,\ R]$이 연주 가능한지를 판별해야 합니다. 악보 전체 구간은 미리 주워지므로, 매번 질의마다 구간이 연주 가능한지를 판별하기 보다 **먼저 $M$으로 연주가 불가능한 구역**을 찾아서 기록해 줍니다. 그럼 질의의 구간이 불가능한 구간을 **포함하는지**만 판별해 주면 구현이 한결 간결해집니다.

### **투 포인터**
불가능한 구간을 구할 때는 **투 포인터**를 이용해 줍니다. 구간의 시작점과 종착점을 각각 포인터로 두고, $M$이하의 양의 정수로 표현이 가능한지를 판별합니다. 최적의 구간을 잡기 위해서 동일 음에 대해서 **최대한 구간을 좁혀줍니다.**

### **전처리**
투 포인터를 이용해서 불가능한 구간을 모두 기록할 때, 보통 질의마다 기록을 수정하거나 그 최솟값 구할 때 이용하는 방법이 **세그먼트 트리**입니다. 그러나, 이 문제에서는 질의마다 수정하는 게 아니라 구간이 가능한지만 판별합니다. 세그먼트 트리는 질의마다 $\mathcal{O}(\log N)$의 시간이 걸리므로 굳이 질의마다 수정이 없는데 이러한 접근은 세그먼트 트리의 용도와 잘 맞지 않습니다.

이보다 전처리 배열을 하나 만들어서 접근하면 시간이 $\mathcal{O}(1)$이면 충분합니다. 

* $minR[L]=R$: $L$부터 $R$까지 연주가 불가능한 구간을 저장하는 배열

배열의 크기와 값은 $N+1$로 충분히 크게 잡아줍니다. **주의**해야 할 점은 $minR$에는 오른쪽 $R$의 값만 저장되어 있으므로 **뒤에서부터 앞으로** $L$에 도달할 때까지 전처리를 해줘야 합니다.

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n, m, q = map(int, input().split())
    p = list(map(int, input().split()))
    minR = [n+1]*(n+1)
    L = 0; inc = dec = 1
    for R in range(1, n):
        if p[R] == p[R-1]: continue
        if p[R] > p[R-1]:
            if dec > 1: L = R-1
            dec = 1; inc += 1
            if inc > m:
                while p[L] == p[L+1]: L += 1
                minR[L+1] = R+1
                L += 1; inc -= 1
        else:
            if inc > 1: L = R-1
            inc = 1; dec += 1
            if dec > m:
                while p[L] == p[L+1]: L += 1
                minR[L+1] = R+1
                L += 1; dec -= 1
    for i in range(n-1, 0, -1): minR[i] = min(minR[i], minR[i+1])
    ans = []
    for _ in range(q):
        L, R = map(int, input().split())
        if minR[L] <= R: ans.append('nej')
        else: ans.append('ja')
    print('\n'.join(ans))
    return
if __name__ == '__main__':
    main()
```
