[문제 링크](https://www.acmicpc.net/problem/13172) 
## **풀이**
### **문제 요약**
$M$개 주사위의 기댓값$\frac{s_i}{n_i}$에 **나머지 연산**을 한 값의 합을 구해야 합니다.

### **모듈러 역원**
보통 컴퓨터 과학이나 알고리즘 문제를 풀 때, 분수(나눗셈)를 나머지 연산의 결과로 출력할 필요가 있는데 이 때 단순히 나눗셈을 해서는 원하는 결과를 얻지 못합니다. 왜냐면 결국 나머지 연산을 해서 얻고자 하는 값은 정수의 형태인데 분수는 실수이므로 분수를 나머지 연산 후 오차 문제가 생기거나 또 나머지 연산과 나눗셈 간에 분배 법칙이 성립하지 않는 등 문제가 생길 수 있기 때문입니다.

이 때 나눗셈은 결국 역수의 곱셈이므로 이러한 역원을 이용한 나머지 연산을 가능하게 하는 것이 **모듈러 역원**입니다. 즉, $\frac{s_i}{n_i}$ 대신 $s_i\times n_i^{-1}$식으로 곱셈으로 바꿔주는 겁니다.

### **페르마의 소정리**
문제에서는 $1,000,000,007$와 같이 큰 소수의 나머지 연산을 한 결과 값을 요구합니다. 소수로 나머지 연산을 할 경우는 페르마의 소정리를 통해서 역원을 찾아줄 수 있습니다.

* **페르마의 소정리**: $P$가 소수이고 $a$가 $P$의 배수가 아닐 때, $a^{P-1} \equiv 1 \pmod P$ 성립합니다. 

구하고자 하는 것은 $\frac{1}{n}$이므로 페르마 소정리를 적용시키면, $n^{M-1} \equiv 1 \pmod M\Rightarrow n^{M-2} \equiv \frac{1}{n} \pmod M$가 됩니다.

## **구현**

<summary>코드</summary>

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

MOD = 1_000_000_007

def main():
    m = int(input())
    ans = 0
    for _ in range(m):
        n, s = map(int, input().split())
        ans = (ans+s*pow(n, MOD-2, MOD))%MOD
    print(ans)
    return
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 1'000'000'007;

ll pw(ll n, ll r, ll MOD){
    ll ret = 1;
    while(r){
        if(r&1) ret = ret*n%MOD;
        n = n*n%MOD;
        r>>=1;
    }
    return ret;
}

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int m; cin >> m;
    ll ans = 0;
    while(m--){
        ll n, s; cin >> n >> s;
        ans = (ans+s*pw(n, MOD-2, MOD))%MOD;
    }
    cout << ans;
    return 0;
}
```
