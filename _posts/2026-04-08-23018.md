[문제 링크](https://www.acmicpc.net/problem/23018) 
## **풀이**
길이 N의 순열에서, 맨 앞에서부터 **그리디**하게 뽑을 수 있으면 무조건 뽑아서 얻는 증가수열의 길이의 기댓값을 구해야 합니다.

### **기댓값**
순열의 첫 번째 원소는 무조건 선택해야 하며, 그다음 원소들을 하나씩 확인 후 선택된 원소들 중 최댓값보다 더 큰 값이면 갱신합니다.

이러한 상황에서 $i$번째 원소가 선택되려면, $1$부터 $i-1$까지의 모든 원소보다 커야 합니다. 순열에서 임의의 $i$개의 원소 중 가장 큰 값이 하필 마지막에 위치할 확률은 정확히 $\frac{1}{i}$입니다. 그럼 기댓값은 아래와 같습니다. 

$$E[X_i] = \sum_{i=1}^{N} \frac{1}{i}$$

간단히 $N$까지 누적합을 구해도 되지만, $N=10^{18}$ 범위까지 누적합을 구하기에는 시간이 너무 오래 걸립니다. 위 수식에 몇 가지 미적분 공식을 적용하면 누적합 계산을 획기적으로 줄일 수 있습니다.

### **오일러-마스케로니 상수+매클로린 공식**
* **작은 $N$**: $N$이 작을 때는 위 식 $E[X_i] = \sum_{i=1}^{N} \frac{1}{i}$을 그대로 적용하면 됩니다. 여기서 작은 $N$의 범위는 $1,000,000$까지입니다.
* **큰 $N$**: $N$이 클 때는 $\sum_{i=1}^{N} \frac{1}{i}$를 적분해서 $\int {1 \over x} \ dx =\ln (\vert x \vert) + \gamma$로 나타낼 수 있고, 상수 $\gamma$를 **오일러-마스케로니 상수**라고 부릅니다. 대략 그 값은 $0.57721566490153286$입니다. 덕분에 모든 $N$에 대한 누적합을 구할 필요 없이 $\mathcal{O}(1)$만에 계산이 가능합니다.

여기서 좀 더 계산을 줄일 수 있는데 $\ln (x) + \gamma$ 공식만으로도 문제를 통과(AC) 하는데 지장은 없습니다. 여기서 **오일러-매클로린 공식**을 쓰면 좀 더 정밀한 소수점 계산이 가능해 누적합 계산을 $10,000$까지 줄일 수 있습니다.

$$\sum_{i=a}^{n} f(i) \approx \underbrace{\int_{a}^{n} f(x) dx}_{\text{1단계: 적분}} + \underbrace{\frac{f(a) + f(n)}{2}}_{\text{2단계: 경계 보정}} + \underbrace{\sum_{k=1}^{p} \frac{B_{2k}}{(2k)!} \left( f^{(2k-1)}(n) - f^{(2k-1)}(a) \right)}_{\text{3단계: 미분 보정}}$$

위 공식이 오일러-매클로린 공식이고 $f(x) = \frac{1}{x}$를 대입 후 위와 같이 3단계 보정을 거치면, $\ln(n) + \gamma + \frac{1}{2n} - \frac{1}{12n^2} + \frac{1}{120n^4}$가 됩니다.

## **구현**

<summary>코드</summary>

```python
import sys
input = lambda: sys.stdin.readline().rstrip()
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)

from math import log
E = 0.57721566490153286
N = 10_000

def main():
    dp = [0]*(N+1)
    for i in range(1, N+1): dp[i] = dp[i-1]+1/i
    t = int(input())
    for i in range(1, t+1):
        n = int(input())
        if n <= N: ans = dp[n]
        else: ans = log(n)+E+1/(2*n)-1/(12*n*n)+1/(120*n*n*n*n)
        print(f'Case #{i}: {ans:.12f}')
    return
if __name__ == "__main__":
    main()
```
```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const long double E = 0.5772156649015328606065120L;
const int N = 10'000;

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    vector<long double> dp(N+1, 0);
    for(int i = 1; i <= N; i++) dp[i] = dp[i-1]+(long double)1/i;
    int t; cin >> t;
    for(int i = 1; i <= t; i++){
        ll n; cin >> n;
        cout << "Case #" << i << ": ";
        cout << fixed << setprecision(12);
        if(n <= N) cout << dp[n];
        else cout << log(n)+E+1.0L/(2*n)-1.0L/(12.0L*n*n)+1.0L/(120.0L*n*n*n*n);
        cout << '\n';
    }
    return 0;
}
```
