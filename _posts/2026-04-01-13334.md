[문제 링크](https://www.acmicpc.net/problem/13334) 
## **풀이**
주어진 철로 길이로 철로를 설치해서 최대 몇 명까지 철로를 이용할 수 있는지를 구해야 합니다. 단순히 철로를 선분마다 비교해서는 시간이 너무 오래 걸립니다. 이럴 때는 시작점과 끝점 중 하나를 선택해 기준점을 잡아줍니다.

### **스위핑**
이 문제에서는 철로와 선분의 끝점을 맞추어 기준을 잡아줍니다. 애당초 선분이 철로의 길이보다 큰 것들은 미리 예외($|h_i - o_i| > d$) 처리로 제외해 줍니다. 그 뒤 끝점을 기준으로 **오름차순 정렬**해 봅니다.

그럼 선분 $[s_i, e_i]$의 끝점을 철로의 끝점이라고 가정해 볼 수 있습니다. 이때 철로의 범위는 $[e_i - d, e_i]$가 됩니다. **우선순위 큐**를 이용해서 시작점을 최소 큐에 넣어줍니다. 그래야 철로에 포함되는 작은 선분부터 차례대로 개수를 셀 수 있습니다.

반복을 통해서 만약 선분의 시작점 $s_i$가 $e_i-d$보다 작다면, 철로를 벗어나므로 우선순위 큐에서 제거해 주는 겁니다. 다음은 큐에 들어있는 개수의 최댓값만 매번 갱신해 주면 최대 몇 명까지 철로를 이용할 수 있는지 구할 수 있습니다.

이와 같이 끝점을 기준점으로 하나씩 빗자루로 쓸어가듯 처리하는 과정을 **스위핑 기법(Sweeping Algorithm)** 이라고 합니다.

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

import heapq

def main():
    n = int(input())
    route = []
    for _ in range(n):
        s, e = map(int, input().split())
        if s > e: s, e = e, s
        route.append((s, e))
    route.sort(key=lambda x: x[1])
    d = int(input())
    hq = []
    ans = 0
    for s, e in route:
        if abs(s-e) > d: continue
        heapq.heappush(hq, s)
        while hq and hq[0] < e-d: heapq.heappop(hq)
        ans = max(ans, len(hq))
    print(ans)
    return  
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
using pii = pair<int, int>;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, d; cin >> n;
    vector<pii> route(n);
    for(int i = 0; i < n; i++){
        int s, e; cin >> s >> e;
        if(s > e) swap(s, e);
        route[i] = {s, e};
    }
    cin >> d;
    sort(route.begin(), route.end(), [](const pii& a, const pii& b){
        return a.second < b.second;
    });
    priority_queue<int, vector<int>, greater<int>> pq;
    int ans = 0;
    for(auto [s, e] : route){
        if(abs(s-e) > d) continue;
        pq.push(s);
        while(pq.size() && pq.top() < e-d) pq.pop();
        ans = max(ans, (int)pq.size());
    }
    cout << ans;
    return 0;
}
```
