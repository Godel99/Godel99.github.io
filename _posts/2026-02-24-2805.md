[문제 링크](https://www.acmicpc.net/problem/2805) 

## **풀이**
### **접근**
나무의 높이를 일일이 다 검사했다간 시간 초과가 날뿐더러 비효율입니다. 목표는 $M$미터의 나무를 가져가기 위한 절단기 높이 $H$의 최댓값입니다.

그러므로 **절단기 높이가 $H$일 때, 나무를 $M$만큼 가져갈 수 있는가?** 라는 결정 문제로 나아갈 수 있습니다. 이를 통해 $H$의 범위를 좁혀나가면서 목표한 최댓값을 찾아봅시다.

### **단조성 : 매개 변수 탐색**
절단기의 높이에 따라 나무를 얻을 수 있는 양이 결정됩니다. 따라서 절단기의 높이를 기준으로 단조성이 유지됩니다. 어떤 기준으로 단조성이 유지된다면, 기준을 통해 **이분 탐색**으로 목표로 하는 최대 높이의 범위를 좁혀가면서 최종 높이를 구할 수 있습니다.

### **이분 탐색**
1. $low=0, \ high=max(trees\ of\ 높이)$ 범위를 설정합니다.
2. 중간 높이 $mid=\frac{(low+high)}{2}$ 보다 큰 나무는 잘라봅니다.
3. 잘린 나무들의 높이를 모두 더하고 그 값($total$)이 $M$보다 크거나 같다면 $low=mid+1$, 작다면 $high=mid-1$입니다. 이걸 $low\leq high$ 까지 반복해 범위를 좁혀갑니다.
4. $low$가 $high$보다 커지면 $high$값이 $M$미터의 나무를 가져가기 위한 절단기 높이 $H$의 최댓값입니다.


## **구현**

<summary>코드</summary>

```python
import sys
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n, m = map(int, input().split())
    tree = tuple(map(int, input().split()))
    low = 0
    high = max(tree)
    while low <= high:
        mid = (low+high)//2
        total = sum(t - mid for t in tree if t > mid)
        if total >= m: low = mid+1
        else: high = mid-1
    print(high)
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0);cout.tie(0);ios::sync_with_stdio(false);
    int n; ll m; cin >> n >> m;
    vector<ll> tree(n);
    ll low, high; low = high = 0;
    for(int i = 0; i < n; i++){ 
        cin >> tree[i];
        if(high < tree[i]) high = tree[i];
    }
    while(low <= high){
        ll mid = (low+high)/2;
        ll total = 0;
        for(auto t : tree){
            if(t > mid) total += t-mid;
        }
        if(total >= m) low = mid+1;
        else high = mid-1;
    }
    cout << high;
    return 0;
}
```
