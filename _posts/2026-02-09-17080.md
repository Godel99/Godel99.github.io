[문제 링크](https://www.acmicpc.net/problem/17080) 
## **풀이**
### 문제 요약
돌의 개수를 통해 선공과 후공 중 누가 승리하는지 구하세요.
### 접근
$n$을 1부터 하나씩 증가시켜가면서 게임 규칙을 적용해 보면 일정하게 규칙이 보입니다.

### 선공 필승
* 돌이 1개, 2개인 경우는 무조건 선공이 이깁니다.
* 돌이 4개라면, 선공이 먼저 2번 돌을 두고 다음에 3번 돌을 놓는다면, $2\rightarrow1\rightarrow3\rightarrow4$로 진행되어 무조건 선공이 이깁니다. 
* 돌이 4개 이상이고 돌이 4배수로 나온다면, 돌이 4개일 경우와 마찬가지로 앞에서부터 4개씩 돌을 지워갈 수 있으므로 무조건 선공이 승리합니다.

### 후공 필승
* 돌이 3개라면 선공이 어떤 돌로 시작을 하던 후공이 이깁니다.
* 돌이 4개 이상이고 4로 나눈 나머지가 3이라면 결국 돌이 3개일 때와 동일한 조건을 만들어지므로 무조건 후공이 승리합니다.

$$
Win(n) = \begin{cases}
2 & \mathrm{if} \ n \equiv 3 \mod{4} \\ 
1 & \mathrm{otherwise}\\ 
\end{cases}
$$


## **구현**
<details markdown="1">
<summary>코드</summary>

```python
import sys
def print(*args, sep=" ", end="\n"): return sys.stdout.write(sep.join(map(str, args)) + end)
def input(): return sys.stdin.readline().rstrip()

def main():
    n = int(input())
    print(2 if n&3 == 3 else 1)
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
