[문제 링크](https://www.acmicpc.net/problem/30804)
## **풀이**
### **투 포인터**
문제의 목표는 **구간의 최대 길이**를 구하는 것입니다. 두 개의 포인터 $left$, $right$ 를 만들어서 $right$ 는 오른쪽 구간을 확장하는 용도로, $left$ 는 왼쪽부터 구간을 축소해 갑시다. 그리고 오른쪽으로 확대를 갈 때마다, 과일 종류의 개수를 확인해 가는 겁니다. 과일 종류의 개수가 갱신될 때마다 그 최댓값을 저장해두면 그 구간의 길이를 구할 수 있습니다.

### **종류별 공간**
과일의 종류는 총 9가지입니다. 그러므로 과일 종류를 저장해 둘 **공간**을 하나 만들어서 관리하면 투 포인터를 쉽게 적용할 수 있습니다.

## **구현**

```python
import sys
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n = int(input())
    a = tuple(map(int, input().split()))
    cnt = [0]*10
    l = t = maxl= 0
    for r in range(n):
        cnt[a[r]] += 1
        if cnt[a[r]] == 1: t += 1
        while t > 2:
            cnt[a[l]] -= 1
            if cnt[a[l]] == 0: t -= 1
            l += 1
        maxl = max(maxl, r-l+1)
    print(maxl)
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
