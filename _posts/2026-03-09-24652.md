## **풀이**

### **이진 트리 설계**
$1$부터 $N$까지 정렬된 수열은 **이진 트리**와 **일대일 대응**을 시킬 수 있습니다. 이분 탐색을 이용해 $K$개의 찾을 수 있는 수와 찾을 수 없는 수를 나눠야 하므로 수열의 $K$위치를 루트 노드로 둡니다. 여기서 루트 노드를 $N$으로 두고, $N$을 기준으로 왼쪽은 그대로 **오름차순**으로, 오른쪽은 **내림차순**으로 된 이진 트리를 설계해 봅니다. 그럼 $1,\ 2,\ 3,\dots,\ N,\ N-1,\dots,\ 5,\ 4$와 같이 $\wedge$모양의 이진 트리를 그려볼 수 있습니다.

따라서, 루트를 기준으로 왼쪽은 이분 탐색으로 찾을 수 있는 **성공** 구역이 되고, 오른쪽은 찾을 수 없는 **실패** 구역이 됩니다.

### **항상 YES**
$1$부터 $N$까지 정렬된 수열 **이진 트리**와 **일대일 대응**이므로 항상 찾을 수 없는 수와 찾을 수 있는 수로 나눌 수 있게 됩니다. 따라서, 항상 ```YES```라는 결과가 나옵니다.

## **구현**
<details markdown="1">
<summary>코드</summary>

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n, k = map(int, input().split())
    print('YES')
    for i in range(1, k): print(i, end=' ')
    for i in range(n, k-1, -1): print(i, end=' ')
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, k; cin >> n >> k;
    cout << "YES\n";
    for(int i = 1; i < k; i++) cout << i << ' ';
    for(int i = n; i >= k; i--) cout << i << ' ';
    return 0;
}
```

* 시간복잡도: $\mathcal{O}(N)$
* 공간복잡도: $\mathcal{O}(1)$
