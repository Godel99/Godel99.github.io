## **풀이**

### **항상 YES**
$1$부터 $N$까지 정렬된 수열은 임의의 트리와 **일대일 대응**을 시킬 수 있습니다. **$K$를 루트 노드**로 하는 **이진 트리**를 생각해 봅니다. 그럼 $K$를 기준으로 **이분 탐색**을 한다면, 왼쪽은 찾을 수 있는 수로 오른쪽은 찾을 수 없는 수로 **항상** 나눌 수 있게 됩니다. 따라서, $K$개의 찾을 수 있는 수와 $N-K$개의 찾을 수 없는 수의 수열을 항상 만들 수 있습니다.

## **구현**
<details markdown="1">
<summary>코드</summary>

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n, k = map(int, input().split())
    print('YES')
    for i in range(1, k): print(i, end=' ')
    for i in range(n, k-1, -1): print(i, end=' ')
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, k; cin >> n >> k;
    cout << "YES\n";
    for(int i = 1; i < k; i++) cout << i << ' ';
    for(int i = n; i >= k; i--) cout << i << ' ';
    return 0;
}
```

### 시간 및 공간 복잡도
* 시간복잡도: $\mathcal{O}(N)$
* 공간복잡도: $\mathcal{O}(1)$
