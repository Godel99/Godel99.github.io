## **풀이**
<p align="center"/><img src="/assets/img/posts/2342.png" alt="DDR">

* 처음 두 발은 가운데에서 시작합니다. 처음을 제외하고 두 발은 같은 자리에 있을 수 없습니다.
* 위 그림에서 처음 가운데에서 이동 비용은 2이고, 대각선 간 이동 비용은 3, 상하좌우 이동 비용은 4입니다.

위 조건을 만족하는 $1,\ 2,\ 3,\ 4$로만 이루어진 지시 수열이 주어질 때, 모든 지시 사항을 만족하는 데 사용되는 최소 비용을 구해야 합니다.

### **DP**
매 지시마다 어느 발이 움직일지 결정해 최소 비용을 구해야 하므로 DP를 설계해 줍니다.

* $dp[i][L][R]$: $i$번째 명령까지 수행했을 때, 왼발이 $L$, 오른발이 $R$에 있을 수 있는 최소 비용
  
위와 같이 DP를 정의하고 5개의 움직임의 비용을 계산해 최솟값을 찾아줘도 됩니다.

### **DP 압축**
어차피 모든 지시를 다 기록할 필요가 없습니다. 또한 **"매 순간 두 발 중 하나는 반드시 직전 위치에 있어야 한다."** 라는 점을 감안해 어느 발의 움직일지 신경 쓰지 말고 **이전 지시와 현재 지시만 누적**해 최솟값을 찾아주면 좀 더 빠릅니다.

* $dp[i]$: 현재 지시를 처리한 후, 지시 위치가 아닌 '나머지 한 발'이 $i$에 있을 때의 최소 비용
  
현재 지시를 $cur$, 이전 지시를 $pre$, 나머지 한 발의 위치를 $i$라 한다면, 점화식은 다음과 같습니다.

* $\displaystyle dp_{new}[pre] = \min_{0 \le i < 5} (dp_{old}[i] + \text{cost}(i, cur))$
* $\displaystyle dp_{new}[i] = dp_{old}[i] + \text{cost}(pre, cur) \quad (\text{for all } i)$

각 지시마다 위 점화식대로 $dp$를 누적하고 업데이트해주면 최솟값을 찾아줄 수 있습니다.

## **구현**

```python
import sys
input = lambda: sys.stdin.readline().rstrip()
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)

from math import inf

def main():
    cmd = [*map(int, input().split())]
    if not cmd or not cmd[0]: print(0); return
    cmd.pop()
    def cst(start, end):
        if start == 0: return 2
        if start == end: return 1
        if abs(start-end) == 2: return 4
        return 3
    dp = [0, inf, inf, inf, inf]
    pre = 0
    for cur in cmd:
        minv = inf
        for i in range(5):
            minv = min(minv, dp[i]+cst(i, cur))
            dp[i] += cst(pre, cur)
        dp[pre] = minv
        pre = cur
    print(min(dp))
    return
if __name__ == "__main__":
    main()
```

#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const int INF = 1e9;

int cst(int start, int end){
    if(start == 0) return 2;
    if(start == end) return 1;
    if(abs(start-end) == 2) return 4;
    return 3;
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int dp[5] = {0, INF, INF, INF, INF};
    int pre = 0, cur;
    while(cin >> cur && cur){
        int minv = INF;
        for(int i = 0; i < 5; i++){
            minv = min(minv, dp[i]+cst(i, cur));
            dp[i] += cst(pre, cur);
        }
        dp[pre] = minv;
        pre = cur;
    }
    cout << min({dp[0], dp[1], dp[2], dp[3], dp[4]});
    return 0;
}
