[문제 링크](https://www.acmicpc.net/problem/33807) 
## **풀이**
유향 비순환 그래프(Directed acyclic graph, DAG)[^1]의 각 간선에 $1$이상 $K$이하의 가중치를 무작위로 부여했을 때, 정점 $1$을 루트로 하고 모든 정점을 포함하는 최소 비용 신장 트리(MST)[^2]를 구성하는 간선의 가중치의 합에 대한 기댓값을 구해야 합니다.

### **기댓값의 선형성**
가중치의 합은 선형적으로 증가합니다. 가중치의 합의 기댓값을 구해야 하므로, 기댓값 또한 선형성을 띄게 됩니다. 따라서, 정점을 트리에 하나씩 추가한다고 생각하고 가중치의 합의 기댓값을 개별적으로 구해서 다 더하면 전체 기댓값을 구할 수 있습니다. 덕분에 트리 구조를 구현할 필요 없이 각 정점의 **진입 차수**에만 집중하면 됩니다.

정점에는 여러 개의 진입 간선이 있을 수 있고, 그 간선의 가중치는 $1$이상 $K$이하로 아직 정해지지 않은 상태입니다. 문제는 가중치가 최솟값을 가져야 한다는 점입니다. 

정점 $v$에 $d$개의 간선이 존재한다면, 그 간선의 가중치의 최솟값을 $x$라고 가정해 봅니다. 간선 하나의 가중치가 $x$보다 클 확률은 $\frac{K - x + 1}{K}$입니다. 간선의 개수가 $d$개이니 전체 확률은 $\underbrace{\frac{K - x + 1}{K} \times \frac{K - x + 1}{K} \times \dots \times \frac{K - x + 1}{K}}_{d \text{ 번}}=\left( \frac{K - x + 1}{K} \right)^d$입니다.

구하고자 하는 기댓값[^3]은 $E[X_v] = \displaystyle\sum_{x=1}^{K} P(X_v \ge x) = \sum_{x=1}^{K} \left( \frac{K-x+1}{K} \right)^d$가 됩니다. 구현을 간결하게 하기 위해서 $i = K-x+1$로 치환하면 아래와 같습니다.

$$E[X_v] = \sum_{x=1}^{K} P(X_v \ge x) = \sum_{x=1}^{K} \left( \frac{K-x+1}{K} \right)^d = \frac{1}{K^d} \sum_{i=1}^{K} i^d$$

### **라그랑주 보간법**
기댓값 공식을 그대로 구현해도 문제는 없습니다. 다만, 좀 더 빠르게 문제를 해결할 수 있는 방법이 있습니다. 일단 $\displaystyle\sum_{i=1}^{K} i^d$는 $K$에 대한 $d+1$차 다항식이므로, $d+2$개의 점만 구한다면 다항식을 구할 수 있습니다. 이를 **라그랑주 보간법**[^4]이라고 합니다. 덕분에 $K$까지 계산할 필요 없이 $d+1$까지만 계산해 다항식을 구하면 $\mathcal{O}(1)$만에 기댓값을 구할 수 있게 됩니다.

아래는 다항식을 구하는 라그랑주 보간법을 기댓값 공식에 적용한 식입니다.

$$P(K) = \sum_{i=0}^{d+1} y_i \times \prod_{j=0, j \neq i}^{d+1} \frac{K - x_j}{x_i - x_j}$$

$$E[X_v] = \underbrace{\frac{1}{K^d}}_{\text{전체 경우의 수}} \times \underbrace{\sum_{i=0}^{d+1} y_i \left( \prod_{j \neq i} \frac{K - x_j}{x_i - x_j} \right)}_{\text{가중치 합의 총량 (라그랑주 보간)}}$$

라그랑주 보간법의 분자는 $j \neq i$ 제외하고 전방과 후방의 누적곱을 구해놓고, 분모는 팩토리오와 모듈러 역원을 적용해서 구해 마지막에 계산해 주면 좀 더 빠르게 해결이 가능합니다.

[^1]: 방향이 있고 특정 노드에서 자기 자신으로 되돌아오는 경로(사이클)가 없는 그래프
[^2]: 신장 트리는 그래프에서 모든 정점에 대한 최소한의 연결만을 남긴 그래프
[^3]: 확률 과정에서 얻을 수 있는 모든 값의 가중 평균
[^4]: $n-1$개의 서로 다른 점을 지나는 $n$차 보간 다항식을 구하는 방법

```python
import sys
input = lambda: sys.stdin.readline().rstrip()
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)

def main():
    MOD = 998244353
    n, m, k = map(int, input().split())
    deg = [0]*(n+1)
    for _ in range(m):
        _, y = map(int, input().split())
        deg[y] += 1
    vcnt = [0]*(m+1)
    maxd = 0
    for i in range(2, n+1):
        if deg[i]: vcnt[deg[i]] += 1
        if deg[i] > maxd: maxd = deg[i]
    fact = [1]*(maxd+3)
    invf = [1]*(maxd+3)
    for i in range(1, maxd+3): fact[i] = (fact[i-1]*i)%MOD
    invf[maxd+2] = pow(fact[maxd+2], MOD-2, MOD)
    for i in range(maxd+1, -1, -1): invf[i] = (invf[i+1]*(i+1))%MOD
    def Sd(d):
        y = [0]*(d+2)
        for i in range(1, d+2): y[i] = (y[i-1]+pow(i, d, MOD))%MOD
        if k <= d+1: return y[k]
        pref = [1]*(d+2)
        suff = [1]*(d+2)
        pref[0] = k
        for i in range(1, d+2): pref[i] = (pref[i-1]*(k-i))%MOD
        suff[d+1] = k-d-1
        for i in range(d, -1, -1): suff[i] = (suff[i+1]*(k-i))%MOD
        ret = 0
        for i in range(d+2):
            num = 1
            if i: num = (num*pref[i-1])%MOD
            if i < d+1: num = (num*suff[i+1])%MOD
            den = (invf[i]*invf[d+1-i])%MOD
            if (d+1-i)%2: den = MOD-den
            ret = (ret+y[i]*num*den)%MOD
        return ret
    ans = 0
    invk = pow(k, MOD-2, MOD)
    for d in range(1, maxd+1):
        if vcnt[d] == 0: continue
        evmd = (Sd(d)*pow(invk, d, MOD))%MOD
        ans = (ans+vcnt[d]*evmd)%MOD
    print(ans)
    return
if __name__ == "__main__":
    main()
```

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 998244353;
int k;
vector<ll> invf;

ll pw(ll n, ll r, ll MOD){
    n %= MOD;
    ll ret = 1;
    while(r){
        if(r&1) ret = ret*n%MOD;
        n = n*n%MOD;
        r >>= 1;
    }
    return ret;
}

ll Sd(int d){
    vector<ll> y(d+2, 0);
    for(int i = 1; i < d+2; i++) y[i] = (y[i-1]+pw(i, d, MOD))%MOD;
    if(k <= d+1) return y[k];
    vector<ll> pref(d+2, 1), suff(d+2, 1);
    pref[0] = k;
    for(int i = 1; i < d+2; i++) pref[i] = (pref[i-1]*(k-i))%MOD;
    suff[d+1] = k-d-1;
    for(int i = d; i > 0; i--) suff[i] = (suff[i+1]*(k-i))%MOD;
    ll ret = 0;
    for(int i = 0; i < d+2; i++){
        ll num = 1;
        if(i) num = (num*pref[i-1])%MOD;
        if(i < d+1) num = (num*suff[i+1])%MOD;
        ll den = (invf[i]*invf[d+1-i])%MOD;
        if((d+1-i)%2) den = MOD-den;
        ret = (ret+y[i]*num%MOD*den)%MOD;
    }
    return ret;
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, m; cin >> n >> m >> k;
    vector<int> deg(n+1, 0);
    for(int i = 0; i < m; i++){
        int x, y; cin >> x >> y;
        deg[y]++;
    }
    vector<int> vcnt(m+1, 0);
    int maxd = 0;
    for(int i = 2; i <= n; i++){
        if(deg[i]) vcnt[deg[i]]++;
        if(deg[i] > maxd) maxd = deg[i];
    }
    vector<ll> fact(maxd+3, 1); invf.assign(maxd+3, 1);
    for(int i = 1; i < maxd+3; i++) fact[i] = (fact[i-1]*i)%MOD;
    invf[maxd+2] = pw(fact[maxd+2], MOD-2, MOD);
    for(int i = maxd+1; i > 0; i--) invf[i] = (invf[i+1]*(i+1))%MOD;
    ll ans = 0;
    ll invk = pw(k, MOD-2, MOD);
    for(int d = 1; d <= maxd; d++){
        if(vcnt[d] == 0) continue;
        ll evmd = (Sd(d)*pw(invk, d, MOD))%MOD;
        ans = (ans+vcnt[d]*evmd)%MOD;
    }
    cout << ans;
    return 0;
}
```
