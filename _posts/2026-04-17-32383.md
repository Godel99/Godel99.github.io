[문제 링크](https://www.acmicpc.net/problem/32383) 
## **풀이**
$N$채의 건물이 나란히 세워져 있을 때, $i$번 건물의 높이는 $H_i$입니다.

*  $a$번 건물과 $b$번 건물 사이에 있는 모든 건물의 높이가 $\min(H_a, H_b)$보다 작다.

위 조건을 만족하며 건물 사이를 이동할 때, 두 건물의 높이 차이의 제곱만큼 체력을 소모합니다. 최소 체력 소모량을 $D(a,\ b)$라 할 때, $\displaystyle\sum_{i=1}^{N-1} \sum_{j=i+1}^{N}{D(i, j)}$를 구해야 합니다.

### **촘촘한 경로**
세 건물 $a,\ b,\ c$에 대해 $H_a > H_b > H_c$라고 한다면, $D(a, c)$를 구한다고 가정해 봅니다.

* $D(a,\ b)=(H_a-H_b)^2$
* $D(b,\ c)=(H_b-H_c)^2$
* $D(a,\ c)=(H_a-H_c)^2$

$H_b - H_c = X$, $H_a - H_b = Y$로 치환하면,

* 직행 비용: $D(a,\ c)=(X+Y)^2 = X^2 + 2XY + Y^2$
* 경유 비용: $D(a,\ b)+D(b,\ c)=X^2 + Y^2$

즉, $(X+Y)^2>X^2 + Y^2$을 통해 직행 비용보단 **경유 비용**이 더 작다는 것을 알 수 있습니다. 결국 최대한 많은 건물을 밟고 이동해야 체력 소모를 줄일 수 있다는 의미입니다. 

### **높은 건물**
높은 건물을 점프할 수 없으므로, 높은 건물을 기준으로 두 그룹을 나눠 볼 수 있습니다. 다시 두 그룹은 그다음으로 높은 건물을 기준으로 또 두 그룹으로 나눌 수 있고 이를 반복한다면, **데카르트 트리**[^1]가 만들어집니다. 즉, 서브 트리 각각이 구하고자 하는 $D$가 되는 것입니다.

단조 스택[^2]을 이용해 데카르트 트리를 구현합니다. 단조 스택에는 건물의 번호를 저장하고, 서브 트리의 크기(노드의 개수)를 저장할 공간도 만들어줍니다. 

1. 내림차순 스택을 유지해 더 높은 건물이 나올 때까지 스택에 넣다가 높은 건물이 나오면, 높은 건물보다 같거나 높은 건물이 나올 때까지 스택에서 건물을 빼서 높은 건물과 스택에서 나온 건물 간에 이동 비용을 계산해 누적합니다.
2. 1번 과정을 반복해 모든 건물을 다 확인 후에도 스택에 남아 있는 건물들은 더 이상 높은 건물이 없다는 의미이므로, 2개씩 짝을 지어 이동 비용을 계산해 줍니다. 이렇게 하면 모든 건물을 밟고 이동한 경로의 비용을 계산할 수 있게 됩니다.

비용을 구하는 공식은 아래와 같이 구할 수 있습니다.

* $\text{기여 횟수} = (\text{자식 } c \text{를 포함한 서브트리의 크기}) \times (N - \text{해당 서브트리 크기})$
* $\text{총 비용} = \sum (\text{높이 차이})^2 \times \text{기여 횟수}$

[^1]: 수열을 바탕으로 만들어지는 이진 트리로, 중위 순회(In-order traversal) 시 원래의 수열이 나타나며 힙(Heap)의 성질을 동시에 만족하는 특수한 자료구조
[^2]: 모노톤 스택(Monotonic Stack), 스택 내의 원소들이 오름차순(단조 증가) 또는 내림차순(단조 감소) 상태를 유지하도록 설계된 특수한 자료구조

```python
import sys
input = lambda: sys.stdin.readline().rstrip()
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)

def main():
    MOD = 1_000_000_007
    n = int(input())
    h = [*map(int, input().split())]
    ch = [1]*n
    st = []
    ans = 0
    for r in range(n):
        while st and h[st[-1]] <= h[r]:
            l = st.pop()
            m = st[-1] if st and h[st[-1]] < h[r] else r
            dif = h[m]-h[l]
            way = (n-ch[l])*ch[l]%MOD
            cst = dif*dif%MOD
            ans = (ans+way*cst)%MOD
            ch[m] += ch[l]
        st.append(r)
    while len(st) > 1:
        r = st.pop()
        l = st[-1] 
        dif = h[l]-h[r]
        way = (n-ch[r])*ch[r]%MOD
        cst = dif*dif%MOD
        ans = (ans+way*cst)%MOD
        ch[l] += ch[r]
    print(ans)   
    return
if __name__ == "__main__":
    main()
```

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 1'000'000'007;

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n; cin >> n;
    vector<int> h(n), ch(n, 1);
    stack<int> st;
    ll ans = 0;
    for(int r = 0; r < n; r++){
        cin >> h[r];
        while(st.size() && h[st.top()] <= h[r]){
            int l = st.top(); st.pop();
            int m = (st.size() && h[st.top()] < h[r] ? st.top() : r);
            ll dif = h[m]-h[l];
            ll way = (ll)(n-ch[l])*ch[l]%MOD;
            ll cst = dif*dif%MOD;
            ans = (ans+way*cst)%MOD;
            ch[m] += ch[l];
        }
        st.push(r);
    }
    while(st.size() > 1){
        int r = st.top(); st.pop();
        int l = st.top();
        ll dif = h[l]-h[r];
        ll way = (ll)(n-ch[r])*ch[r]%MOD;
        ll cst = dif*dif%MOD;
        ans = (ans+way*cst)%MOD;
        ch[l] += ch[r];
    }
    cout << ans;
    return 0;
}
```
