[문제 링크](https://www.acmicpc.net/problem/28240) 
## **풀이**
### 접근
원형의 사이클이 아닌 일렬로 구성된 선형 모양을 떠올려 봅시다. $2번\rightarrow3번\rightarrow4번\rightarrow\cdots$ 이렇게 쭉 패스한다면 선형 모양을 그려 볼 수 있습니다.

문제는 모든 $i$번에 대해서 Kobe, LeBron, Curry, Jordan 간의 패스와 1번과 n번의 패스만 따로 연결해 주면 됩니다. 나머지는 전부 $x$축($y=0$)에서 일렬로 패스를 하면 문제가 없습니다.

예를 들어, Kobe, LeBron은 $y$축으로부터 1 이상의 위치에서 패스를 하면 겹치는 일이 없고 마찬가지로 Curry, Jordan $y$축으로부터 -1 이상 위치에서 패스를 하면 서로 겹칠 일이 없이 나머지 학생들과도 문제가 없습니다.

마지막 1번과 n번만 따로 연결해 주면 되는데 Kobe, LeBron, Curry, Jordan이 범위가 n번까지 가능하므로 **안전**하게 $2n$까지 넓혀줍니다. 왜냐면 1번이 $(1, 0)$에서 n번 $(n, 2n)$까지가 직선으로 연결했을 시 다른 간선과 겹치지 않기 때문입니다.($2n$이 최소 범위는 아닙니다)

## **구현**

<summary>코드</summary>

```python
import sys
def print(*args, sep=" ", end="\n"): return sys.stdout.write(sep.join(map(str, args)) + end)
def input(): return sys.stdin.readline().rstrip()

def main():
    n = int(input())
    a, b, c, d = map(int, input().split())
    ans = []
    for i in range(1, n):
        ans.append(str(i)+' ')
        if i == a or i == b: ans.append('1')
        elif i == c or i == d: ans.append('-1')
        else: ans.append('0')
        ans.append('\n')
    ans.append(str(n)+' ')
    if n == a or n == b: ans.append(str(2*n))
    else: ans.append(str(-2*n))
    print(''.join(ans))
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, a, b, c, d; cin >> n >> a >> b >> c >> d;
    for(int i = 1; i < n; i++){
        cout << i << ' ';
        if(i == a || i == b) cout << 1 << '\n';
        else if(i == c || i == d) cout << -1 << '\n';
        else cout << 0 << '\n';
    }
    cout << n << ' ';
    if(n == a || n == b) cout << 2*n << '\n';
    else cout << -2*n << '\n';
    return 0;
}
```
