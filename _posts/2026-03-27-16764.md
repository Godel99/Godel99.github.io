[문제 링크](https://www.acmicpc.net/problem/16764) 
## **풀이**
### **문제 요약**
5개의 원소를 가진 집합 $N$개가 주어질 때, 그중 공통된 원소가 없는 **쌍의 개수**를 구해야 합니다.

### **포함-배제의 원리**
집합 $N$개 중 2개를 하나의 쌍으로 두고, 5개의 원소에서 1개가 겹칠 경우, 2개가 겹칠 경우, $\dots$ 등 5개까지 겹칠 경우를 모두 계산해서 전체의 경우 $_nC_2$에서 겹치는 경우를 모두 빼줘야 합니다. 이럴 경우 조합론에서 여러 개의 합집합의 크기를 구할 때 **포함-배제의 원리**를 이용합니다.

예를 들어, 원소 1개가 겹치는 경우는 원소 2개가 겹치는 경우를 포함합니다. 그래서 원소 1개가 겹치는 경우의 수와 원소 2개가 겹치는 경우의 수를 구해서 서로 빼주면 중복되는 경우를 제외할 수 있습니다. 마찬가지로 원소가 3개가 겹치는 경우는 원소가 2개가 겹치는 경우에서 이미 제외해 줬으므로 다시 추가합니다.

이 문제에서 포함-배제의 원리를 일반화하면, 아래와 같습니다.

$$\text{정답} = \binom{N}{2} - (\text{1개\ 겹침} - \text{2개\ 겹침} + \text{3개\ 겹침} - \text{4개\ 겹침} + \text{5개\ 겹침})$$

집합의 개수가 최대 $50,000$이고, ${}_5C_1 + {}_5C_2 + {}_5C_3 + {}_5C_4 + {}_5C_5 = 2^5 - 1 = 31$ 겹침의 경우의 수가 $31$개이므로 $50,000\times 31$ 대략 150만 개 경우를 다뤄야 합니다. 

31개의 경우는 **비트마스킹**을 쓰면 좋을 거 같고, 각종 조합에 관련된 라이브러리를 이용해도 좋습니다. **해시**를 이용하는 방법과 **정렬**을 이용하는 방법 모두 가능합니다. 다만, 정렬을 이용한 방법은 마지막에 제외되는 연산만 따로 한 번 더 연산해 줘야 합니다.

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

from collections import Counter
from itertools import combinations

def main():
    n = int(input())
    v = Counter()
    for _ in range(n):
        a = sorted(map(int, input().split()))
        for r in range(1, 6):
            for comb in combinations(a, r):
                v[comb] += 1
    ans = n*(n-1)//2
    for comb, cnt in v.items():
        if cnt < 2: continue
        ans += (-1 if len(comb)&1 else 1)*cnt*(cnt-1)//2
    print(ans)
    return
if __name__ == '__main__':
    main()
```

```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
using ai5 = array<int, 5>;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n; cin >> n;
    vector<ai5> v; v.reserve(n*31);
    for(int i = 0; i < n; i++){
        ai5 id; cin >> id[0] >> id[1] >> id[2] >> id[3] >> id[4];
        sort(id.begin(), id.end());
        for(int j = 1; j < 32; j++){
            ai5 a = {0,}; int idx = 0;
            for(int k = 0; k < 5; k++) if(j>>k & 1) a[idx++] = id[k];
            v.push_back(a);  
        }
    }
    sort(v.begin(), v.end());
    ll ans = (ll)n*(n-1)/2, cnt = 1;
    for(int i = 1; i < v.size(); i++){
        if(v[i] == v[i-1]) cnt++;
        else{
            int sz = 0;
            while(sz < 5 && v[i-1][sz]) sz++;
            ans += (sz&1 ? -1 : 1)*cnt*(cnt-1)/2;
            cnt = 1;
        }
    }
    int sz = 0;
    while(sz < 5 && v.back()[sz]) sz++;
    ans += (sz&1 ? -1 : 1)*cnt*(cnt-1)/2;
    cout << ans;
    return 0;
}
```
