[문제 링크](https://www.acmicpc.net/problem/34464) 
## **풀이**
### 문제 요약
$N \times M$ 크기의 격자에 칸마다 음이 아닌 수가 하나씩 쓰여 있습니다. 두 플레이어는 번갈아 가며 칸 하나를 골라 거기 적힌 수에서 1을 뺍니다. 수가 음수가 되거나, 인접한 두 수의 값이 같아지게 만들면 집니다.

선공과 후공 중 누가 이기는지 구하세요.

### 접근
이 게임은 실은 게임 시작부터 **승패가 결정된 게임**입니다. 그래서 플레이어가 어떤 수를 두느냐, 격자 값 간의 위치가 큰 의미가 없습니다. 

그렇다면 주어진 격자 값들을 통해 누가 이길지 **최종 값**을 알 수 있습니다.

에를 들어, 두 개의 격자에 10, 5 값이 있다고 치면 최종 값은 $5+1=6$이 됩니다. 10에서 1씩을 빼가며 6에 도달하기 전까지는 격자 간 위치나 어떤 수를 두느냐는 큰 의미가 없습니다. 그러기에 최종 값을 미리 설정해 두고 $10-6=4$(기존 값 - 최종 값)에서 4가 **홀짝**인지로 구분해 누가 승리할지를 미리 알 수 있습니다.

### 최종 값 DP
* $dp[i][j]$: 격자 위치(i, j)에서 더 이상 줄일 수 없는 최종 값

초기에는 $-1$로 $dp$를 초기화해줍니다.
  
최종 값은 위의 예시를 통해서도 알 수 있듯이 **더 이상 줄일 수 없는 수**입니다. 10, 5에서 6이 최종 값이고 1을 줄이면 승패가 결정이 됩니다.

### 정렬
격자의 위치는 큰 의미가 없으므로 기존 값을 **오름차순으로 정렬**해 최종 값을 구해봅시다. 왜 하필 오름차순이냐면 최종 값은 정의대로 더 이상 줄일 수 없는 수이므로 작은 값을 기준으로 먼저 보는 겁니다. 예를 들어 10, 5의 경우도 5를 먼저 확인해 6이란 최종 값을 알아야 10에서 얼마를 더 줄 일 수 있는지를 쉽게 판단할 수 있게 됩니다.

정렬된 격자를 이동하며 $max(최종\ 값,\ 주위의\ 최종\ 값+1)$를 통해 최종 값을 결정하게 됩니다.

### 방문 여부 + 경계 처리
$dp$를 간단하게 $-1$로 초기화해 방문 여부와 경계 처리를 동시에 해주면 좀 더 간단하게 구현할 수 있습니다.

### 홀짝성(Nim / Sprague–Grundy 이론)
기존 격자 값에서 최종 값을 빼면 격자에서 움직일 수 있는 크기가 나옵니다. 그 값을 모두 더해 홀짝 여부만 판단하면 누가 승리하는지 알 수 있습니다.

홀짝 여부는 간단히 XOR 연산과 AND 연산을 통해 구할 수 있습니다. XOR 연산으로 합을 구하고 AND 연산으로 홀짝 여부를 판단합니다.

```python
import sys
def print(*args, sep=" ", end="\n"): return sys.stdout.write(sep.join(map(str, args)) + end)
def input(): return sys.stdin.readline().rstrip()

dx = (1, -1, 0, 0); dy = (0, 0, 1, -1)

def main():
    t = int(input())
    for _ in range(t):
        n, m = map(int, input().split())
        dp = [[-1]*(m+2) for _ in range(n+2)]
        v = []
        for i in range(1, n+1):
            a = tuple(map(int, input().split()))
            for j in range(1, m+1):
                v.append((a[j-1], i, j))
        v.sort()
        for _, i, j in v:
            for dir in range(4): dp[i][j] = max(dp[i][j], dp[i+dy[dir]][j+dx[dir]]+1)
        ans = 0
        for x, i, j in v: ans ^= (x-dp[i][j])
        print('Yes' if ans&1 else 'No')
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
using ai3 = array<int, 3>;
const int dx[] = {1, -1, 0, 0}, dy[] = {0, 0, 1, -1};

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int t; cin >> t;
    while(t--){
        int n, m; cin >> n >> m;
        vector<vector<int>> dp(n+2, vector<int>(m+2, -1));
        vector<ai3> v;
        for(int i = 1; i <= n; i++){
            for(int j = 1; j <= m; j++){
                int x; cin >> x;
                v.push_back({x, i, j});
            }
        }
        sort(v.begin(), v.end());
        for(auto& [x, i, j] : v){
            for(int dir = 0; dir < 4; dir++) dp[i][j] = max(dp[i][j], dp[i+dy[dir]][j+dx[dir]]+1);
        }
        int ans = 0;
        for(auto& [x, i, j] : v) ans ^= (x-dp[i][j]);
        cout << (ans&1 ? "Yes\n" : "No\n");
    }
    return 0;
}
```
### 시간 및 공간 복잡도
* 시간복잡도: $\mathcal{O}(T \times NM \log(NM))$
* 공간복잡도: $\mathcal{O}(N \times M)$
