[문제 링크](https://www.acmicpc.net/problem/2449) 
## **풀이**
$N$개의 전구가 일렬로 있는데, 인접한 전구의 동일한 색에 대해 한 번에 바꿀 수 있습니다. 그렇다면 모든 전구의 색을 통일하기 위해 최소 몇 번의 행동이 필요한지 구해야 합니다.

### **DP**
특정 **구간**의 색을 바꿀 때마다 최소 행동을 기록해야 하므로 DP가 필요해 보입니다. DP를 다음과 같이 정의합니다.

* $DP[L][R]$: 구간$[L,\ R]$의 전구의 색을 동일하게 만들기 위한 최소 행동의 수

### **양쪽 끝 전구**
**인접**한 동일 색의 전구는 한 번에 색을 바꿀 수 있습니다. 그렇다면, **색의 영향력**을 기준으로 전구를 두 종류로 나눠서 생각해 볼 수 있습니다. **양쪽 끝 전구**는 자신들의 옆 전구의 밖에 영향을 줄 수 없습니다. 그러나, 양쪽 끝 전구를 제외한 그 사이의 전구들은 양방향으로 영향을 줄 수 있습니다.

그렇다면 영향력이 작은 전구의 색으로 모든 전구 색을 맞춘다면, 그 반대 방향에 대해서는 굳이 색을 바꿀 필요가 없기에 **최소**의 행동을 보장하는 **그리디**함을 볼 수 있습니다. 양쪽 끝 전구 중 왼쪽 끝을 기준으로 해도 괜찮고 오른쪽 끝을 기준으로 해도 좋습니다.

$$DP[l][r] = \min_{l \le m < r} \{ DP[l][m] + DP[m+1][r] + (A[l] \neq A[m+1]) \}$$

위 계산식은 왼쪽($l \le m < r$)을 기준으로 DP를 계산한 겁니다. 참고로, 전구의 동일한 색을 하나로 통일해서 새 $A$배열을 만들어서 풀면 좀 더 빠릅니다.

```python
import sys
input = lambda: sys.stdin.readline().rstrip()
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)

def main():
    n, k = map(int, input().split())
    b = [*map(int, input().split())]
    a = [b[0]]
    for i in range(1, n):
        if b[i] != b[i-1]: a.append(b[i])
    m = len(a)
    dp = [[0]*(m) for _ in range(m)]
    for d in range(1, m):
        for l in range(m-d):
            r, mind = l+d, d
            for mid in range(l, r):
                mind = min(mind, dp[l][mid]+dp[mid+1][r]+(a[l] != a[mid+1]))
            dp[l][r] = mind
    print(dp[0][-1])
    return
if __name__ == "__main__":
    main()
```

#include <bits/stdc++.h>

int main() {

    for(int i = 1; i < n; i++) if(b[i] != b[i-1]) a.push_back(b[i]);
    int m = a.size();
    vector<vector<int>> dp(m, vector<int>(m, 0));
    for(int d = 1; d < m; d++){
        for(int l = 0; l < m-d; l++){
            int r = l+d, mind = d;
            for(int mid = l; mid < r; mid++){
                mind = min(mind, dp[l][mid]+dp[mid+1][r]+(a[l] != a[mid+1]));
            }
            dp[l][r] = mind;
        }
    }
    cout << dp[0][m-1];
    return 0;
}
