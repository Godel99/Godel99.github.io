[문제 링크](https://www.acmicpc.net/problem/28068) 
## **풀이**
$N$권의 책을 다 읽을 수 있는지 판별해야 합니다. **정렬**을 이용해서 **그리디**한 상황을 만들어야 쉽게 풀 수 있습니다.

### **분류**
먼저 책을 두 종류로 분류합니다.

* **재밌는 책**($a\leq b$): 책을 읽은 후 읽기 전보다 즐거움이 감소하지 않은 경우
* **재미없는 책**($a>b$): 책을 읽은 후 읽기 전보다 즐거움이 감소하는 경우 

재밌는 책을 **우선** 읽어주는 게 최선입니다. $a$를 기준으로 **오름차순 정렬**해 순서대로 읽어줍니다. 끝까지 읽을 수 없다면 완독이 불가능합니다.

### **재미없는 책**
재밌는 책을 먼저 읽어줬으니 이제 재미없는 책을 읽어줘야 합니다. 예를 들어, 재미없는 책이 $x,\ y$이 두 권이 있을 경우, 어느 책을 읽던 즐거움은 감소합니다. 그렇다면 즐거움 감소를 적게 하려면, 책을 통해 얻을 수 있는 즐거움이 클수록 좋습니다. 따라서, $b$를 기준으로 **내림차순 정렬**을 해 순서대로 읽어줍니다. 이 경우도 끝까지 읽을 수 없다면 완독이 불가능한 겁니다.

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n = int(input())
    pb, mb = [], []
    for _ in range(n):
        a, b = map(int, input().split())
        if a <= b: pb.append((a, b))
        else: mb.append((b, a))
    pb.sort()
    mb.sort(reverse=True)
    joy = 0
    for a, b in pb:
        if a > joy: print(0); return
        joy += b-a
    for b, a in mb:
        if a > joy: print(0); return
        joy -= a-b
    print(1)
    return  
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;
using pii = pair<int, int>;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n; cin >> n;
    vector<pii> pb, mb;
    for(int i = 0; i < n; i++){
        int a, b; cin >> a >> b;
        if(a <= b) pb.push_back({a, b});
        else mb.push_back({b, a});
    }
    sort(pb.begin(), pb.end());
    sort(mb.begin(), mb.end(), greater<pii>());
    ll joy = 0;
    for(auto [a, b] : pb){
        if(a > joy) return !(cout << 0);
        joy += b-a;
    }
    for(auto [b, a] : mb){
        if(a > joy) return !(cout << 0);
        joy -= a-b;
    }
    cout << 1;
    return 0;
}
```
