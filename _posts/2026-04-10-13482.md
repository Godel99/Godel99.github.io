[문제 링크](https://www.acmicpc.net/problem/13482) 
## **풀이**
랜덤으로 값이 정해지는 8비트 부호 없는 정수들과 사칙연산, min, max 연산을 이용해, 50% 이상의 확률로 0~255 사이의 원하는 값이 나오게끔 하는 식을 만들어야 합니다. 최대 26개의 매크로 식을 선언할 수 있으며, 매크로를 포함해 전체 식의 길이는 256글자를 넘을 수 없습니다.

### **확률 농축**
사칙연산, min, max 연산만을 이용해 0~255의 수를 모두 만들기 위해서는 특정수 하나를 $100\%$에 가깝게 만들어줘야 합니다. 그래야 그 특정수를 빼거나 나눠줘서 0, 1을 만들 수 있습니다. 1을 만들면 $1+1=2$를 통해 2를 만들 수 있고 2를 통해 **이진법**으로 0~255 사이의 수를 모두 만들 수 있습니다.

여기서 $max$라는 연산을 통해 가장 큰 값 255를 특정해 볼 수 있습니다. 먼저 ```a=?max?```는 $a$가 255일 확률이 $0.78\%$밖에 되지 않습니다. 이 확률을 좀 더 농축해서 $100\%$에 가깝게 만들어줘야 합니다. 반복문을 이용해 15번 매크로를 돌려주면 $2^{15}=32,768$번 농축이 가능하고, 그럼 $255$를 실패할 확률 $P_{fail}$이 $P_{fail} = \left(\frac{255}{256}\right)^{32768} \approx 1.05 \times 10^{-56}$까지 떨어집니다. 여기서 좀 더 $100\%$에 가깝게 하기 위해 다시 4번 이상 $max$연산을 더해주면 $255$를 실패할 확률이 $P_{fail}=(1.05 \times 10^{-56})^4 \approx 1.2 \times 10^{-224}$이므로 현대 컴퓨터의 정밀도에서는 사실상 $100\%$에 근접합니다. 글자 수가 256개로 제한되니 4번 이상에서 적당히 정해주면 됩니다.

### **비트마스킹+이진법**

이제 $255$라는 수를 특정했으니 $255-255=0,\ \frac{255}{255}=1$를 만들 수 있고 이를 통해 $1,\ 2,\ 4,\ 8,\ 16,\ 32,\ 64,\ 128$의 8개의 매크로 식을 만들 수 있습니다. 이제 **비트마스킹**과 **이진법**을 조립해 0~255 사이의 수를 모두 만들 수 있습니다.

총 26개의 매크로 모두를 사용하고 대략 글자 수 218자를 써서 문제를 해결했습니다.

```python
import sys
input = lambda: sys.stdin.readline().rstrip()
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)

from string import ascii_lowercase

def main():
    n = int(input())
    a_z = ascii_lowercase
    print('a=?max?')
    for i in range(1, 16): print(f'{a_z[i]}={a_z[i-1]}max{a_z[i-1]}')
    print('q=pmaxpmaxpmaxpmaxp')
    print('r=q-q')
    print('s=q/q')
    for i in range(19, 26): print(f'{a_z[i]}={a_z[i-1]}+{a_z[i-1]}')
    if n:
        ans = []
        bit = ['s', 't', 'u', 'v', 'w', 'x', 'y', 'z']
        for i in range(8):
            if n & (1<<i): ans.append(bit[i])
        print('+'.join(ans))
    else: print('r')
    return
if __name__ == "__main__":
    main()
```

    if(n){
        vector<char> ans;
        char bit[] = {'s', 't', 'u', 'v', 'w', 'x', 'y', 'z'};

        cout << ans[0];

}
