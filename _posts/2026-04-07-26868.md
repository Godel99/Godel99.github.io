[문제 링크](https://www.acmicpc.net/problem/26868) 
## **풀이**
삼각함수(```sin```, ```cos```, ```tan```)와 역삼각함수(```asin```, ```acos```, ```atan```)만을 써서 주어진 $a,\ b$ 값을 이용해 1000번 안에 0에서 $\frac{a}{b}$를 만들어야 합니다. 짧은 경로를 찾을 필요는 없으며, 정답은 여러 개가 나올 수 있습니다.

### **삼각함수와 관계**
먼저 이 문제를 풀기 위해서 필요한 삼각함수의 관계를 몇 가지 알고 가야 합니다. 

두 변의 길이가 각각 $\sqrt a$, $\sqrt b$인 직각삼각형의 빗변의 길이는 $\sqrt{a+b}$입니다. 이를 삼각함수와 역삼각함수의 관계를 이용해 표현하면 아래와 같습니다.

* $\cos(0)=1$
* $\sin (\arctan (\sqrt{\frac{a}{b}})) = \sqrt{\frac{a}{a+b}}$
* $\tan (\arccos (\sqrt{\frac{a}{b}})) = \sqrt{\frac{b-a}{a}}$

$\sin (\arctan (\sqrt{\frac{a}{b}})) = \sqrt{\frac{a}{a+b}}$와 $\tan (\arccos (\sqrt{\frac{a}{b}}) ) = \sqrt{\frac{b-a}{a}}$를 조합하면 아래와 같습니다.

* $\tan (\arccos (\sin (\arctan (\sqrt{\frac{a}{b}}) ) ) ) = \sqrt{\frac{b}{a}}$

### **유클리드 호제법**
0에서 $\frac{a}{b}$를 만들 방법을 찾아야 하지만, 거꾸로 $\frac{a}{b}$에서 0으로 찾아가서 출력을 거꾸로 해주면 문제가 더 쉽게 풀립니다.

식 $\sin (\arctan (\sqrt{\frac{a}{b}}) ) = \sqrt{\frac{a}{a+b}}$을 보면 결국 분모 $b$에 $a$가 더해진 것을 알 수 있습니다. 그렇다면 만들고자 하는 $\frac{a}{b}$는 이전 식 $\sin (\arctan (\sqrt{\frac{a}{b-a}}))=\sqrt\frac{a}{b}$에서 분모에 $a$가 더해져 나온 것을 알 수 있습니다. 더불어 $\tan (\arccos (\sin (\arctan (\sqrt{\frac{a}{b}}) ) ) ) = \sqrt{\frac{b}{a}}$는 $a,\ b$의 위치를 바꾼 것입니다.

이와 연결되는 개념이 **유클리드 호제법**입니다. 유클리드 호제법은 최대공약수$GCD$를 구하는 알고리즘이지만, 유클리드 호제법은 $a \leq b$일 때, $b$를 $a$로 나눈 나머지를 구하며, 최대공약수를 찾습니다. 나눗셈은 결국 빼기의 반복이므로, 분모에서 $a$를 더해가는 게 아니라 역으로 빼가는 식으로 $\sin (\arctan (\sqrt{\frac{a}{b}})) = \sqrt{\frac{a}{a+b}}$를 쓸 수 있게 됩니다. 마찬가지로 $b-a$를 하다가 $a>b$가 되면, $\tan (\arccos (\sin (\arctan (\sqrt{\frac{a}{b}}) ) ) ) = \sqrt{\frac{b}{a}}$를 통해 $a$와 $b$를 바꿔주고 이를 반복하면 결과적으로 0이나 1에 도달하게 됩니다.

한 가지 주의할 점은 삼각함수의 관계가 $\sqrt{\frac{a}{b}}$와 같이 제곱근이므로, 처음 시작할 때 $a^2,\ b^2$로 시작하면 계산하기 용이합니다.

```python
import sys
input = lambda: sys.stdin.readline().rstrip()
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)

def main():
    a, b = map(int, input().split())
    a *= a; b *= b
    ans = []
    while a != b:
        if a < b:
            b -= a
            ans.extend(['sin', 'atan'])
        else:
            a, b = b, a
            ans.extend(['tan', 'acos', 'sin', 'atan'])
    ans.append('cos')
    print(len(ans))
    print(*reversed(ans))
    return
if __name__ == "__main__":
    main()
```
```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

stack<string> ans;

void gcd(int a, int b){
    if(!a) return;
    if(a == b) return ans.push("cos");
    if(a > b){
        ans.push("tan");
        ans.push("acos");
        ans.push("sin");
        ans.push("atan");
        return gcd(b, a);
    }
    ans.push("sin");
    ans.push("atan");
    return gcd(a, b-a);
}

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int a, b; cin >> a >> b;
    a *= a; b *= b;
    gcd(a, b);
    cout << ans.size() << '\n';
    while(ans.size()){
        cout << ans.top() << ' '; ans.pop();
    }
    return 0;
}
```
