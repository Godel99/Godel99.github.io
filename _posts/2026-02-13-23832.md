[문제 링크](https://www.acmicpc.net/problem/23832) 
## **풀이**
### 접근
1부터 $N$까지의 서로소의 개수를 구하라는 문제입니다. 1부터 $N$까지 최대공약수가 1개인 서로소를 구해도 되겠지만, 비효율입니다.

좀 더 쉽게 풀기 위해선 **오일러의 피 함수**를 이용합니다.

### 오일러 피 함수 + 소수 판별

$$
\begin{gathered}
\varphi(n)=|\{m:1\leq m \leq n,\ gcd(m,\ n)=1\}| \\
\Rightarrow \varphi(n)= n \times \prod_{p|n} \frac{p-1}{p}
\end{gathered}
$$

오일러 피 함수의 공식은 위와 같습니다. 위 공식을 적용하면 문제에서 요구하는 서로소의 개수를 구할 수 있습니다.

* $phi[i]$: $i$보다 작은 수 중에서 $i$와 서로소인 수의 개수

$phi[i]$ 배열 하나 만들고 일단 $phi[i]=i$로 초기화를 해줍니다. 그런 뒤 $i$가 소수라면 오일러 피 함수를 적용해 $phi$ 배열에 저장해 줍니다.

어떻게 오일러 피 함수와 소수 판별이 동시에 가능하냐면, 오일러 피 함수가 적용될 때마다 합성수를 $i$로 나눠주면서 더 작은 소인수로 만들어 줍니다. 그 과정에서 소인수가 더 이상 나눠지지 않게 되면 그게 바로 소수가 됩니다.

$phi$ 배열의 합이 서로소의 총개수가 됩니다.

## **구현**

<summary>코드</summary>

```python
import sys
def print(*args, sep=" ", end="\n"): return sys.stdout.write(sep.join(map(str, args)) + end)
def input(): return sys.stdin.readline().rstrip()

def main():
    n = int(input())
    phi = [i for i in range(n+1)]
    for i in range(2, n+1):
        if phi[i] == i:
            for j in range(i, n+1, i):
                phi[j] -= phi[j]//i
    print(sum(phi[2:]))
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n; cin >> n;
    vector<int> phi(n+1);
    for(int i = 0; i <= n; i++) phi[i] = i;
    for(int i = 2; i <= n; i++){
        if(phi[i] == i){
            for(int j = i; j <= n; j += i) phi[j] -= phi[j]/i;
        }
    }
    ll ans = 0;
    for(int i = 2; i <= n; i++) ans += phi[i];
    cout << ans;
    return 0;
}
```
### 시간 및 공간 복잡도
* 시간복잡도: $\mathcal{O}(N \log \log N)$
* 공간복잡도: $\mathcal{O}(N)$
