## **풀이**
### **범위**
인접한 수열의 최대공약수(GCD)가 모두 다르게 수열을 나열해야 합니다. 특정 조건에 만족하도록 수열을 강제로 나열해야 하므로 특히 범위가 중요합니다.

$N$ 의 범위는 **$2\leq N\leq 20,000$** 이고, 수열의 원소 $A_i$ 의 범위는 **$1 \leq A_{i} \leq 10^{8}$** 입니다.

### **$GCD(x,\ x+1)=1$**
**인접한 두 수는 서로 서로소**라는 수학적 원리를 이용해서 인접한 수열의 최대공약수가 서로 다르게 수열을 강제로 나열해 줍니다.

특정한 변수 $i,\ j$ 를 번갈아가며, $i$ 를 1부터 10,000까지 증가시키고 $j$를 19,999부터 10,000까지 감소시켜가면서 $i \times j$ 해주는 겁니다. $i \times j$ 의 범위는 최대 $10,000 \times 10,000=10^8$ 이내이므로 만족합니다.

$\gcd(i \cdot j,\ i \cdot (j-1)) = i \cdot \gcd(j,\ j-1) = i \cdot 1 = i$

$\gcd(i \cdot j,\ (i+1) \cdot j) = j \cdot \gcd(i,\ i+1) = j \cdot 1 = j$

위와 같이 인접한 항은 서로소라는 성질을 이용해서 $i,\ j$로 최대공약수를 강제할 수 있게 됩니다. 

위 방법을 그대로 출력하면 $19999,\ 19998,\ 39996,\ 39994,\ 59991,\ 59988,\ 79984,\ 79980, \dots$ 나오며 인접한 최대공약수를 구하면, $1,\ 19998,\ 2,\ 19997,\ 3,\ 19996,\ 4, \dots$ 와 같이 최대공약수를 서로 **겹치지 않고** 다르게 나열할 수 있습니다. 

$N$ 이 최대 20,000 일 경우 최대공약수는 19,999개이므로 $j$의 시작 범위를 19,999부터 잡아준 겁니다. $N$이 20,000일 경우만 따로 처리해주면 됩니다.

## **구현**

<summary>코드</summary>

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n = int(input())
    i, j = 1, 19999
    for k in range(n-1):
        print(i*j, end=' ')
        if k&1: i += 1
        else: j -= 1
    if n < 20000: print(i*j)
    else: print(100000000)
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>

int main(){

    for(int k = 0; k < n-1; k++){
        cout << i*j << ' ';
        if(k&1) i++;
        else j--;
    }
    if(n < 20000) cout << i*j;
    else cout << 100000000;
    return 0;
}
```
