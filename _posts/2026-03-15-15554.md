[문제 링크](https://www.acmicpc.net/problem/15554) 
## **풀이**
$N$개의 순서쌍 $(A_i,\ B_i)$에서 일부를 선택해, $\sum B-(A_{max}-A_{min})$의 최댓값을 구해야 합니다.

순서쌍을 $A$를 기준으로 **정렬**해 주면, 연속 구간에서 최적의 해가 나옵니다.

### **증명**
$A$를 기준으로 **정렬**하면, 순서쌍에서 시작점 $L$과 끝점 $R$까지의 작품을 선택했을 때 가치 $V$는 다음과 같습니다.

$$V(L, R) = \sum_{k=L}^{R} B_k - (A_R - A_L)$$

가치 $B$의 **누적합**을 구해주면, 다음과 같습니다.

$$S_i = \sum_{k=0}^{i-1} B_k$$

구간 $(L, R)$의 합은 $S_{R+1} - S_L$로 치환할 수 있습니다.

$$V(L, R) = (S_{R+1} - S_L) - (A_R - A_L)$$

이를 재배치하면, 다음과 같은 수식을 얻을 수 있습니다.

$$V(L, R) = (S_{R+1} - A_R) - (S_L - A_L)$$

목표는 $V(L, R)$의 최대화이기 때문에 이를 표현하면 다음과 같습니다.

$$MaxV(R) = (S_{R+1} - A_R) - \min_{0 \le L \le R}(S_L - A_L)$$

즉, 구간 $R$을 오른쪽으로 한 칸씩 늘려가면서 **왼쪽 구간 $L$의 최솟값**을 찾아주는 겁니다. 결국 $\min_{0 \le L \le R}(S_L - A_L)$이 최소가 되면 전체 $MaxV(R)$가 최대가 됩니다.

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

from math import inf

def main():
    n = int(input())
    a = sorted(list(map(int, input().split())) for _ in range(n))
    L, R, pres = inf, 0, 0
    for i in range(n):
        L = min(L, pres-a[i][0])
        pres += a[i][1]
        R = max(R, pres-a[i][0]-L)
    print(R)
if __name__ == '__main__':
    main()
```

    sort(a.begin(), a.end());
    ll L = inf, R = 0, pres = 0;
    for(int i = 0; i < n; i++){
        L = min(L, pres-a[i].first);
        pres += a[i].second;
        R = max(R, pres-a[i].first-L);
    }
    cout << R;
    return 0;
}
