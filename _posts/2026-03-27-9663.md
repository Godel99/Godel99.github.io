[문제 링크](https://www.acmicpc.net/problem/9663)
## **풀이**
체스 게임에서 여왕(Queen)은 가로, 세로, 대각선 끝까지 이동할 수 있습니다. $N \times N$ 체스판에서 $N$개의 여왕을 놓을 때, 서로 공격할 수 없도록 놓을 **방법의 수**를 구해야 합니다.

### **한 줄에 하나씩!**
가로, 세로, 대각선 어디로든 이동이 가능하므로 먼저 행에 하나씩 여왕을 놓습니다. **DFS**를 이용해서 행에 하나씩 놓을 때는 이전 여왕과 이동이 충돌 조건을 만족하는지 확인합니다. 충돌하지 않을 때마다 방법의 수를 1씩 증가시킵니다. 만약 놓을 자리가 없다면 이전(**백트래킹**)으로 되돌아가서 이전 여왕의 위치를 바꿔봅니다.

### **충돌 조건**
1. 세로 열 확인: 세로 열에서 충돌이 있는지 확인해 줍니다.
2. 대각선 확인: 대각선은 **우하향**과 **우상향** 방향 2개를 확인해 줍니다.

충돌 조건을 좀 더 빠르게 하려면 세로 열과 두 대각선에 대한 배열을 각각 만들어줘서 **방문 처리**를 통해 각 조건을 확인해 줍니다. 아래는 각각의 충돌 조건을 검사할 배열입니다.

* $v1[col]$: 열을 확인하는 배열입니다. 크기는 $N$이면 충분합니다.
* $v2[row+col]$: 우상향 대각선을 확인하는 배열입니다. $row+col$의 값이 같을 때, ```/``` 우상향 방향입니다. 크기는 $2N$이면 충분합니다.
* $v3[row-col+N]$: 우하향 대각선을 확인하는 배열입니다. $row-col$의 값이 같을 때 ```\``` 우하향 방향입니다. 마지막에 $N$을 더해준 이유는 음수를 방지하기 위함입니다. 크기는 $2N$이면 충분합니다.

## **구현**

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n = int(input())
    v1, v2, v3 = [0]*n, [0]*n*2, [0]*n*2
    cnt = 0
    def dfs(r):
        nonlocal cnt
        if r == n: cnt += 1; return
        for c in range(n):
            if v1[c] or v2[r+c] or v3[r-c+n]: continue
            v1[c] = v2[r+c] = v3[r-c+n] = 1
            dfs(r+1)
            v1[c] = v2[r+c] = v3[r-c+n] = 0
    dfs(0)
    print(cnt)
    return
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int n, cnt;
vector<bool> v1, v2, v3;

void dfs(int r){
    if(r == n){cnt++; return;}
    for(int c = 0; c < n; c++){
        if(v1[c] || v2[r+c] || v3[r-c+n]) continue;
        v1[c] = v2[r+c] = v3[r-c+n] = 1;
        dfs(r+1);
        v1[c] = v2[r+c] = v3[r-c+n] = 0;
    }
}

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    cin >> n;
    v1.assign(n, 0); v2.assign(n*2, 0); v3.assign(n*3, 0);
    dfs(0);
    cout << cnt;
    return 0;
}
```
