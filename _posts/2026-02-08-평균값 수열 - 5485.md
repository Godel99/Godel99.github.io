[문제 링크](https://www.acmicpc.net/problem/5485) 
## **풀이**
### 문제 요약
평균값 수열 $m_i$를 만족하는 수열 $s_i$의 개수를 구하세요.

### 접근
입력으로 $m_i$가 주워지므로, 하나의 $s_i$를 정한다면 나머지 모든 $s$의 값들도 $m$을 통해서 연쇄적으로 알 수 있게 됩니다. 

문제에선 특정 수열 $s_i$를 구하는 게 아니라 평균값 수열을 만족하는 수열의 개수를 구하라 했으므로 $s_i$ 범위를 구하면 그게 정답이 됩니다.

### 범위

$s_i$의 범위를 $s_i \in [low,\ high]$ 라고 정한다면, $s_{i+1}$의 범위는 $s_{i+1}=2m_i-s_i$이므로 $s_{i+1} \in [2m_i-high,\ 2m_i-low]$가 될 수 있습니다.

여기서 $s_{i+1}$의 최댓값의 범위는 $2m_i-low$인데, $2m_i-low$는 $m_{i+1}$를 초과할 수 없습니다. 왜냐하면 아래의 식을 보면 이유를 알 수 있습니다.

$$
\begin{gathered}
m_i= \frac{s_i+s_{i+1}}{2} \Rightarrow s_{i+1}=2m_i-s_i \\
s_i \leq s_{i+1} \Rightarrow s_i \leq 2m_i-s_i \Rightarrow s_i \leq m_i 
\end{gathered}
$$

$s_i \leq s_{i+1}$인 이유는 $s_i$이 비감소 수열이기 때문입니다.

그러므로 $s_{i+1}$의 최댓값 $high$는 $min(2m_i-low,\ m_{i+1})$범위로 정해질 수 있습니다.

## **구현**

<summary>코드</summary>

```python
import sys
def print(*args, sep=" ", end="\n"): return sys.stdout.write(sep.join(map(str, args)) + end)
def input(): return sys.stdin.readline().rstrip()

def main():
    n = int(input())
    low = int(input())
    high = cur = int(input())
    for _ in range(2, n):
        nxt = int(input())
        low, high = 2*cur-high, min(2*cur-low, nxt)
        cur = nxt
    print(max(0, high-low+1))
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n; cin >> n;
    ll low, high, cur; cin >> low >> high; cur = high;
    for(int i = 2; i < n; i++){
        ll nxt, tmp = low; cin >> nxt;
        low = 2*cur-high;
        high = min(2*cur-tmp, nxt);
        cur = nxt;
    }
    cout << max(0ll, high-low+1);
    return 0;
}
```
