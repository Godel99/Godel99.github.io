[문제 링크](https://www.acmicpc.net/problem/17218) 
## **풀이**
### 접근
DP를 이용해 두 개의 패스워드에서 동일한 알파벳의 개수를 각각 기록해 줍시다. 패스워드 각각의 동일한 알파벳 개수의 가장 긴 것이 가장 길게 겹치는 패스워드가 될테니 그게 정답입니다.

패스워드 하나하나 DP에 기록을 해야 하니 마지막 DP에서 되돌아가면서 알파벳을 찾아줘야겠네요.

### DP
* $dp[i][j]$: 문자열 $a$, $b$에서 $a[i-1]$와 $b[j-1]$를 끝으로 가장 긴 **공통** 부분 문자열의 길이

$a[i-1]$와 $b[j-1]$가 같다면 $dp[i][j]$에 $dp[i-1][j-1]+1$을 구해주고 아니라면, 

$max(dp[i-1][j],\ dp[i][j-1])$로 각 패스워드 중 가장 긴 공통 부분의 길이를 구해줍니다.

### 백 트래킹
가장 긴 공통된 길이를 구해줬으니 뒤로 되돌아가면서 알파벳을 찾아줍시다. 간단하게 스택을 이용하던가 출력을 반대로 해 줍시다.

```python
import sys
def print(*args, sep=" ", end="\n"): return sys.stdout.write(sep.join(map(str, args)) + end)
def input(): return sys.stdin.readline().rstrip()

def main():
    a = input(); n = len(a)
    b = input(); m = len(b)
    dp = [[0]*(m+1) for _ in range(n+1)]
    for i in range(1, n+1):
        for j in range(1, m+1):
            if a[i-1] == b[j-1]: dp[i][j] = dp[i-1][j-1]+1
            else: dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    ans = []
    while n and m:
        if a[n-1] == b[m-1]:
            ans.append(a[n-1])
            n -= 1
            m -= 1
        elif dp[n-1][m] > dp[n][m-1]: n -= 1
        else: m -= 1
    print(''.join(reversed(ans)))
if __name__ == '__main__':
    sys.exit(main())
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    string a, b; cin >> a >> b;
    int n = a.size(), m = b.size();
    vector<vector<int>> dp(n+1, vector<int>(m+1, 0));
    for(int i = 1; i <= n; i++){
        for(int j = 1; j <= m; j++){
            if(a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1]+1;
            else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
    stack<char> ans;
    while(n && m){
        if(a[n-1] == b[m-1]){
            ans.push(a[n-1]);
            n--;
            m--;
        }
        else if(dp[n-1][m] > dp[n][m-1]) n--;
        else m--;
    }
    while(ans.size()){
        cout << ans.top();
        ans.pop();
    }
    return 0;
}
```
### 시간 및 공간 복잡도
* 시간복잡도: $\mathcal{O}(N \times M)$
* 공간복잡도: $\mathcal{O}(N \times M)$
