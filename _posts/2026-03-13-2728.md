[문제 링크](https://www.acmicpc.net/problem/2728) 
## **풀이**
가게마다 마가리타를 하나씩만 살 수 있고, 가지고 있는 돈으로 더 이상 살 수 없을 때까지 가게마다 판매 중인 마가리타를 살 경우의 조합의 수를 구해야 합니다.

더 이상 살 수 없다는 것은 최대한 많은 마가리타를 사고, 남은 예산으로는 **가장 싼 마가리타조차 살 수 없는 상태**를 의미합니다.

### **관점 전환**
그렇다면 더 이상 살 수 없는 상태의 경우의 수는 **가장 싼 마가리타를 살 수 없는 경우**와 **가장 싼 마가리타를 살 수 있는 경우**로 나눠서 생각해 볼 수 있습니다.

### **가장 싼 마가리타를 살 수 있는 경우**
이 경우는 가장 싼 마가리타를 제외하고 총예산에서 가장 싼 마가리타를 빼 버리면, 다시 **직전의 상황**과 똑같아진다는 것을 알 수 있습니다. 즉, **두 번째로 싼 마가리타를 사지 않았을 경우**가 **가장 싼 마가리타를 살 수 있는 경우**를 포함하게 됩니다. 이러면 가장 싼 마가리타를 사지 않았을 경우와 살 경우를 모두 포함하게 되어 최종적으로 **더 이상 살 수 없는 상태의 조합의 수**를 구할 수 있게 됩니다.

### **일반화**
이를 일반화하면 마가리타를 가격순으로 **정렬**했을 때, 앞에서부터 순서대로 $i$개의 마가리타를 모두 사고 $i+1$번째 마가리타를 사지 않았을 경우를 모두 더한 값과 같다는 것을 알 수 있습니다.

### **역순 + 누적합**
가격순으로 정렬된 마가리타를 $i$까지 구매하므로 이를 **누적합**으로 구해줍니다. 다음은 역순으로 $i+1$번째 마가리타를 사지 않았을 경우부터 가장 싼 마가리타를 사지 않았을 경우까지를 모두 더해 간다면 $\mathcal{O}(V\times D)$내의 복잡도로 문제를 해결할 수 있습니다.

### **배낭+DP**
일반화를 통해 **배낭+DP**를 설계하면, 아래와 같습니다.

* $dp[x]$: 기준점($i+1$)보다 비싼 마가리타들의 합으로 $x$의 금액을 만드는 경우의 수

### **예외 처리**
DP 설계에 따라 가정을 가장 비싼 마가리타조차 살 수 없는 상태라고 전제했으므로, 처음부터 **총예산으로 모든 마가리타를 살 수 있는 경우**와 **단 하나의 마가리타를 살 수 없는 경우**를 먼저 예외 처리를 해줘야 합니다.

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    t = int(input())
    for _ in range(t):
        v, d = map(int, input().split())
        a = [0]+list(map(int, input().split()))
        if sum(a) <= d: print(1); continue
        a.sort()
        if a[1] > d: print(0); continue
        pref = [0]*(v+1)
        for i in range(1, v+1): pref[i] = pref[i-1]+a[i]
        dp = [0]*(d+1)
        dp[0] = 1
        ans = 0
        for i in range(v, 0, -1):
            r = d-pref[i-1]
            if r >= 0: 
                for j in range(r, max(-1, r-a[i]), -1): ans += dp[j]
            for j in range(d, a[i]-1, -1): dp[j] += dp[j-a[i]]
        print(ans)
if __name__ == '__main__':
    main()
```

#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int t; cin >> t;
    while(t--){
        int v, d; cin >> v >> d;
        vector<int> a(v+1, 0);
        int s = 0;
        for(int i = 1; i <= v; i++){
            cin >> a[i];
            s += a[i];
        }
        if(s <= d){cout << 1 << '\n'; continue;}
        sort(a.begin(), a.end());
        if(a[1] > d){cout << 0 << '\n'; continue;}
        vector<int> pref(v+1, 0);
        for(int i = 1; i <= v; i++) pref[i] = pref[i-1]+a[i];
        vector<ll> dp(d+1, 0);
        dp[0] = 1;
        ll ans = 0;
        for(int i = v; i > 0; i--){
            int r = d-pref[i-1];
            if(r >= 0) for(int j = r; j > max(-1, r-a[i]); j--) ans += dp[j];
            for(int j = d; j >= a[i]; j--) dp[j] += dp[j-a[i]];
        }
        cout << ans << '\n';
    }
    return 0;
}

* 공간복잡도: $\mathcal{O}(D)$
