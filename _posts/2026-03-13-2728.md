[문제 링크](https://www.acmicpc.net/problem/2728) 
## **풀이**
가게마다 마가리타를 하나씩만 살 수 있고, 가지고 있는 돈으로 더 이상 살 수 없을 때까지 가게마다 판매 중인 마가리타를 살 경우의 조합의 수를 구해야 합니다.

더 이상 살 수 없다는 것은 최대한 많은 마가리타를 사고, 남은 예산으로는 **가장 싼 마가리타조차 살 수 없는 상태**를 의미합니다.

### **관점 전환**
그렇다면 더 이상 살 수 없는 상태의 경우의 수는 **가장 싼 마가리타를 살 수 없는 경우**와 **가장 싼 마가리타를 살 수 있는 경우**를 더한 값과 같습니다.

### **가장 싼 마가리타를 살 수 없는 경우**
가장 싼 마가리타를 제외한 나머지 마가리타를 사고 더 이상 살 수 없는 상태입니다. 여기서 **배낭+DP**를 이용해서 가장 싼 마가리타를 살 수 없는 경우의 수를 구해줍니다.

* $dp[x]$: 가장 싼 마가리타를 제외한, $x$의 금액을 사용해서 마가리타를 구매하는 경우의 수

### **가장 싼 마가리타를 살 수 있는 경우**
이 경우는 가장 싼 마가리타가 처음부터 존재하지 않았고 가장 싼 마가리타 다음으로 싼 마가리타를 가장 싼 마가리타라고 가정해 봅니다. 그럼 처음 예산에서 가장 싼 마가리타의 가격을 빼고, 가장 싼 마가리타를 제외한다면, **가장 싼 마가리타를 살 수 있는 경우의 수**는 **두 번째로 싼 마가리타를 사지 않았을 경우**가 포함하게 된다는 것을 알 수 있습니다.

이를 **일반화**하면 마가리타를 가격순으로 **정렬**했을 때, 앞에서부터 순서대로 $i$개의 마가리타를 모두 사고 $i+1$번째 마가리타를 사지 않았을 경우를 모두 더한 값과 같다는 것을 알 수 있습니다.

### **역순 + 누적합**
일반화를 이용해 가격순으로 정렬된 마가리타 가격의 누적합을 미리 구해 놓고 이를 역순으로 $i+1$번째 마가리타를 사지 않았을 경우부터 가장 싼 마가리타를 사지 않았을 경우까지를 모두 더해 간다면 $\mathcal{O}(V\times D)$내의 복잡도로 문제를 해결할 수 있습니다.

따라서, 역순과 누적합에 알맞게 $dp$도 가장 비싼 마가리타를 제외하고 그보다 싼 마가리타를 모두 산 경우로 의미를 바꿔줍니다.

* $dp[x]$: 가장 비싼 마가리타를 제외한, $x$의 금액을 사용해서 구매하는 경우의 수

### **예외 처리**
처음 가정을 가장 싼 마가리타조차 살 수 없는 상태라고 전제했으므로, 처음부터 **총예산으로 모든 마가리타를 살 수 있는 경우**와 **단 하나의 마가리타를 살 수 없는 경우**를 먼저 예외 처리를 해줘야 합니다.

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    t = int(input())
    for _ in range(t):
        v, d = map(int, input().split())
        a = [0]+list(map(int, input().split()))
        if sum(a) <= d: print(1); continue
        a.sort()
        if a[1] > d: print(0); continue
        pref = [0]*(v+1)
        for i in range(1, v+1): pref[i] = pref[i-1]+a[i]
        dp = [0]*(d+1)
        dp[0] = 1
        ans = 0
        for i in range(v, 0, -1):
            r = d-pref[i-1]
            if r >= 0: 
                for j in range(r, max(-1, r-a[i]), -1): ans += dp[j]
            for j in range(d, a[i]-1, -1): dp[j] += dp[j-a[i]]
        print(ans)
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int t; cin >> t;
    while(t--){
        int v, d; cin >> v >> d;
        vector<int> a(v+1, 0);
        int s = 0;
        for(int i = 1; i <= v; i++){
            cin >> a[i];
            s += a[i];
        }
        if(s <= d){cout << 1 << '\n'; continue;}
        sort(a.begin(), a.end());
        if(a[1] > d){cout << 0 << '\n'; continue;}
        vector<int> pref(v+1, 0);
        for(int i = 1; i <= v; i++) pref[i] = pref[i-1]+a[i];
        vector<ll> dp(d+1, 0);
        dp[0] = 1;
        ll ans = 0;
        for(int i = v; i > 0; i--){
            int r = d-pref[i-1];
            if(r >= 0) for(int j = r; j > max(-1, r-a[i]); j--) ans += dp[j];
            for(int j = d; j >= a[i]; j--) dp[j] += dp[j-a[i]];
        }
        cout << ans << '\n';
    }
    return 0;
}
```

### 시간 및 공간 복잡도
* 시간복잡도: $\mathcal{O}(T\times V\times D)$
* 공간복잡도: $\mathcal{O}(D)$
