[문제 링크](https://www.acmicpc.net/problem/31572) 
## **풀이**
비밀 문자열 $S$가 팰린드롬인지를 판별하는 함수 ```guess_palindromicity```를 작성해야 합니다. 문제에서 제공하는 두 함수 ```count_pair```, ```find_character```를 이용해서 팰린드롬을 판별해야 하는데 두 함수를 **최소로 호출**해야 부분 점수에서 만점을 받을 수 있습니다. 만점의 조건은 두 질의(함수) ```count_pair```, ```find_character```를 $A,\ B$라 할 때, 질의 횟수가 $A \leq \lfloor \frac{N}{2} \rfloor+1,\ B\leq1$를 만족해야 합니다.

### **질의**
```count_pair```는 **3개의 원소**에서 동일한 쌍의 개수를 반환하므로, 반환 값은 **0, 1, 3**뿐입니다. 

```find_character```는 특정 구간에서 원소의 존재 여부를 판별해 줍니다.

두 질의의 특성과 팰린드롬의 특성을 고려해서 최적의 해법을 찾아야 합니다. 팰린드롬은 **대칭성**을 가지고 있고, 문자열 길이의 **홀짝** 여부가 팰린드롬을 판별하는데 중요합니다.

### **문자열의 길이가 홀수**
길이가 홀수라면 가운데 원소를 기준으로 양쪽이 대칭을 이룹니다. ```count_pair```를 이용해 양쪽 끝 두 개의 원소부터 가운데로 좁혀가며 가운데 원소와 묶어서 매번 질의를 해줍니다. 그럼 $\lfloor \frac{N}{2} \rfloor$개의 질의가 소모됩니다. 다음은 질의 결과에 따른 유추할 수 있는 내용입니다.

* **0**이 반환된 경우: 양쪽 원소가 서로 다릅니다. 주어진 문자열 $S$는 팰린드롬이 아닙니다. 
* **1**이 반환된 경우: 양쪽 원소가 서로 같거나, 두 양쪽 원소 중 하나가 가운데 원소와 같습니다.
* **3**이 반환된 경우: 세 원소가 모두 같습니다.

**1**이 반환될 경우를 좀 더 생각해 봅니다. 만약 양쪽 원소가 같을 경우는 가운데 원소와는 반드시 양쪽 원소가 다를 겁니다. **1**이 반환된 경우들 중에 **하나라도** 가운데 원소와 같은 값을 가지면, 팰린드롬이 성립하지 않습니다. 이를 확인해 주기 위해서 질의 ```find_character```를 이용해 가운데 원소와 나머지 양쪽의 원소들 중 일치하는 게 있는지 확인해 줍니다. 그럼 문자열의 팰린드롬 여부를 알 수 있습니다.

### **문자열의 길이가 짝수**
짝수의 경우 가운데 두 개의 원소를 기준으로 대칭적 구조를 이루지만, $N-1$번째 위치를 가운데 원소라고 가정하고 홀수일 때와 똑같이 질의를 해 줍니다. 이 때 질의 ```count_pair```는 $\frac{N-2}{2}=\lfloor \frac{N}{2} \rfloor-1$회 호출됩니다. 그럼 2번의 질의를 더 할 수 있는데, 2번의 질의를 **가운데 두 원소**가 같은지 여부를 판별하는 데 사용해 줍니다.

* 이전 질의 중에 ```count_pair```의 결과로 **한 번**이라도 **3**이 나왔을 경우를 따져봅니다. 그럼 이때는 가운데 왼쪽 원소와 같은 원소를 하나 알 수 있으니, 그 하나의 원소와 가운데 왼쪽, 오른쪽 원소가 같은지를 ```count_pair```를 통해 확인해 줍니다.
* 그 외에는  ```count_pair```의 결과로 **1만** 나왔을 경우입니다. 그럼 맨 왼쪽 원소와 가운데 두 원소가 같은지 ```count_pair```를 통해 확인해 줍니다. 이전 ```count_pair```의 양쪽 끝 두 원소와 가운데 왼쪽 원소에서 결과가 1이 나왔으므로, 맨 왼쪽 원소와 가운데 두 원소의 질의에서 1이 나오지 않으면 팰린드롬은 성립하지 않습니다. 왜냐면 만약 3이 나오면 맨 왼쪽 원소와 가운데 두 원소가 같다는 것이고, 이전 양쪽 끝 두 원소와 가운데 왼쪽 원소의 질의에서 1이 나왔기에 맨 왼쪽 원소와 가운데 왼쪽 원소가 같다는 것이고 그럼 **맨 왼쪽과 오른쪽 원소가 다르다**는 의미가 되어 팰린드롬이 성립하지 않습니다. 0이 나왔을 경우는 짝수 길이에서 두 가운데 원소가 서로 다르다는 것이므로 이 경우도 팰린드롬이 성립하지 않습니다.

  * 마지막 남은 질의 ```count_pair```를 이용해 가운데 오른쪽 원소와 맨 왼쪽 원소가 같은지도 확인해 줘야 합니다. 아직까지는 맨 왼쪽과 가운데 왼쪽 원소가 다르다는 것만 확인했지 가운데 두 원소가 같은지 다른지를 확인하지 못했습니다. 이를 위해서 맨 왼쪽과 오른쪽 원소, 가운데 오른쪽 원소에 대해서 질의를 해줍니다. 이미 맨 양쪽의 원소가 서로 같다는 것을 확인했으므로, 이 경우도 1이 나오지 않는다면 가운데 두 원소가 다르다는 것이므로 팰린드롬이 성립하지 않습니다.

## **구현**
<details markdown="1">
<summary>코드</summary>

```c++
#include<bits/stdc++.h>
using namespace std;

extern int count_pair(int, int, int);
extern int find_character(int, vector<int>);

int guess_palindromicity(int n){
    vector<int> one;
    int thr = -1;
    for(int i = 0; i < (n-1)/2; i++){
        int qry = count_pair(i, (n-1)/2, n-1-i);
        if(qry == 0) return 0;
        if(qry == 1){
            one.push_back(i);
            one.push_back(n-1-i);
        }
        else thr = i;
    }
    if(~n&1){
        if(thr < 0){
            if(count_pair(0, (n-1)/2, (n+1)/2) != 1) return 0;
            if(count_pair(0, (n+1)/2, n-1) != 1) return 0;
        }
        else{
            if(count_pair((n-1)/2, (n+1)/2, thr) != 3) return 0;
        }
    }
    return (one.empty() || !find_character((n-1)/2, one));
}
```

* 시간복잡도: $\mathcal{O}(N)$
* 공간복잡도: $\mathcal{O}(N)$
