[문제 링크](https://www.acmicpc.net/problem/11660) 
## **풀이**
질의 $M$마다 루프를 반복하면 복잡도가 $\mathcal{O}(N^2\times M)$이므로 최대 $100,000 \times 1,024^2$라는 어마어마한 연산을 해야 합니다. 구간 합에 대한 연산을 줄일 수 있도록 DP를 이용해 누적합을 미리 구해 줍니다.

### **DP**
DP를 이용해서 미리 누적합 배열을 만들어 줍니다.

* $dp[i][j]$: $(1,\ 1)$에서 $(i,\ j)$까지의 사각형 안의 모든 수의 합

### **누적합**

$$dp[i][j]=a[i][j]+dp[i-1][j]+dp[i][j-1]-dp[i-1][j-1]$$

$a$를 현재 값이라고 한다면, **위쪽 직사각형** $dp[i-1][j]$와 **왼쪽 직사각형** $dp[i][j-1]$를 더해주고 중복된 구역 $-dp[i-1][j-1]$ 빼주면 $dp[i][j]$를 구할 수 있습니다.

그럼 구간 합은 간단히 $\text{구간 합} = dp[x2][y2]-dp[x1-1][y2]-dp[x2][y1-1]+dp[x1-1][y1-1]$로 구할 수 있습니다.

## **구현**

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n, m = map(int, input().split())
    dp = [[0]*(n+1) for _ in range(n+1)]
    for i in range(1, n+1): dp[i][1:] = list(map(int, input().split()))
    for i in range(1, n+1):
        for j in range(1, n+1): dp[i][j] += dp[i-1][j]+dp[i][j-1]-dp[i-1][j-1]
    for _ in range(m):
        x1, y1, x2, y2 = map(int, input().split())
        s = dp[x2][y2]-dp[x1-1][y2]-dp[x2][y1-1]+dp[x1-1][y1-1]
        print(s)
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, m, a; cin >> n >> m;
    vector<vector<int>> dp(n+1, vector<int>(n+1, 0));
    for(int i = 1; i <= n; i++) for(int j = 1; j <= n; j++){
        cin >> a;
        dp[i][j] = a+dp[i-1][j]+dp[i][j-1]-dp[i-1][j-1];
    }
    while(m--){
        int x1, y1, x2, y2; cin >> x1 >> y1 >> x2 >> y2;
        int s = dp[x2][y2]-dp[x1-1][y2]-dp[x2][y1-1]+dp[x1-1][y1-1];
        cout << s << '\n';
    }
    return 0;
}
```

* 공간복잡도: $\mathcal{O}(N^2)$
