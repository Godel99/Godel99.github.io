[문제 링크](https://www.acmicpc.net/problem/20531)
## **풀이**
친구 관계가 **가능한 경우의 수**를 구해야 합니다.

### **분리 집합**
어느 무리의 한 명과 친구가 되면 그 무리 전체와 친구가 될 수 있습니다. 어느 무리의 한 명과 다른 무리의 한 명이 친구가 되면 두 무리는 친구관계가 되어 하나의 무리로 볼 수 있습니다. 이러한 과정은 **분리 집합**을 이용해 해결해 줍니다.

### **제 2종 스털링 수와 벨 수(Bell Number)**
무리를 분리 집합으로 관리할 수 있게 되면, 무리에 한 명의 새로운 친구가 들어올 경우와 그렇지 않을 경우를 판단하기 위해 **제 2종 스털링 수와 벨 수(Bell Number)** 를 이용해 줍니다. 제 2종 스털링 수를 수식으로 표현하면 다음과 같습니다.

$$B_n = \sum_{k=1}^{n} S(n,\ k)$$

정의는 **$n$개의 원소로 구성된 집합을 $k$개로 분할하는 경우의 수**입니다. 즉, 제 2종 스털링 수를 이용해 새 친구와 기존의 무리와 관계를 경우의 수로 나타낼 수 있습니다. 

새 친구는 기존의 무리에 편입되어 친구가 될 수도 있고 또는 자신이 새로운 무리를 형성할 수도 있습니다. 이 두 경우의 수를 더하면 다음과 같은 수식으로 표현할 수 있습니다.

$$S(n,\ k)=S(n-1,\ k-1)+S(n-1,\ k)\times k$$

제 2종 스털링 수를 이용해 경우의 수를 구했으므로 스털링 수의 **누적합**을 구해주면 벨 수를 구할 수 있습니다. 벨 수가 문제에서 요구한 친구 관계가 가능한 경우의 수가 됩니다. 벨 수는 스털링 수와 다음과 같은 관계를 가집니다.

$$B_n = \sum_{k=1}^{n} S(n,\ k) \Rightarrow B_{n+1} = \sum_{k=0}^{n} \binom{n}{k} B_k$$

위 수식을 이용해 $N$까지 미리 **벨 수**를 구해주고 **분리 집합**에서 무리가 합쳐질 때마다 $N$을 1씩 줄여가며 가능한 경우의 수를 출력해 주면 됩니다.

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

MOD = 1_000_000_007

def main():
    n, m = map(int, input().split())
    dp = [[0]*(n+1) for _ in range(n+1)]
    for i in range(1, n+1):
        dp[i][0] = dp[i][1] = 1
        for j in range(2, i+1):
            dp[i][j] = (dp[i-1][j]*j+dp[i-1][j-1])%MOD
            dp[i][0] = (dp[i][0]+dp[i][j])%MOD
    par = [-1]*(n+1)
    def f(x):
        if par[x] < 0: return x
        par[x] = f(par[x])
        return par[x]
    def u(x, y):
        nonlocal n
        x = f(x); y = f(y)
        if x == y: return
        n -= 1
        if par[x] > par[y]: x, y = y, x
        par[x] += par[y]
        par[y] = x
    for _ in range(m):
        x, y = map(int, input().split())
        u(x, y)
        print(dp[n][0])
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 1'000'000'007;
int n, m;
vector<vector<ll>> dp;
vector<int> par;

int f(int x){
    if(par[x] < 0) return x;
    par[x] = f(par[x]);
    return par[x];
}

void u(int x, int y){
    x = f(x), y = f(y);
    if(x == y) return;
    n--;
    if(par[x] > par[y]) swap(x, y);
    par[x] += par[y];
    par[y] = x;
}

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    cin >> n >> m;
    dp.assign(n+1, vector<ll>(n+1, 0));
    par.assign(n+1, -1);
    for(int i = 1; i <= n; i++){
        dp[i][0] = dp[i][1] = 1;
        for(int j = 2; j <= i; j++){
            dp[i][j] = (dp[i-1][j]*j+dp[i-1][j-1])%MOD;
            dp[i][0] = (dp[i][0]+dp[i][j])%MOD;
        }
    }
    while(m--){
        int x, y; cin >> x >> y;
        u(x, y);
        cout << dp[n][0] << '\n';
    }
    return 0;
}
```
