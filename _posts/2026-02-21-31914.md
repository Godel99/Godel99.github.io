## **풀이**
### **접근**
모든 직사각형은 $(0,0)$ 점에 고정되어 있습니다. 브루트 포스로 모든 직사각형을 만들어서 정을 구하기엔 시간 초과 우려가 큽니다.

직사각형이 최대한 많은 점을 포함할수록 문제에서 요구하는 최댓값은 증가합니다. 그러나 문제의 조건에서 직사각형에 모든 색의 점이 포함되어선 안 됩니다.

직사각형을 가로든 세로든 쭉 늘려봅시다. 예를 들어 가로를 쭉 늘린다고 가정하면, 가로 쪽에서 점이 추가될 때마다 세로 쪽 점들은 **단조적으로 감소**하거나 유지될 수밖에 없습니다. 왜냐면 모든 색이 포함되지 않아야 하기 때문에 가로에서 점이 추가될 때 모든 색이 채워진다면 세로에서 점을 줄여가야 하기 때문입니다. 

이런 식으로 접근한다면 굳이 모든 직사각형을 만들 필요 없이 가로 방향의 점을 추가할 때마다 세로 방향의 점을 제외하는 방법으로 최댓값을 찾아낼 수 있습니다.

이는 반대로 세로 방향에서 추가하고 가로 방향에서 제외를 해도 동일합니다.

### **정렬 + 우선순위 큐 + 스위핑**
가로 방향의 점들을 쭉 늘려가는 방법으로 문제를 해결해 봅시다. 이를 위해서는 $x좌표\to y좌표$ 기준으로 오름차순 정렬을 해주면 됩니다.

가로 방향에서 점을 늘려가다가 모든 색이 포함될 시 세로 방향의 **가장 위**의 점부터 직사각형을 잘라나가는 겁니다. 가장 위에서부터 자르기 위해선 세로 방향의 값이 가장 큰 것부터 잘라내야 최대한 많은 점을 포함합니다. 가장 큰 값부터 찾아내기 위해서 **우선순위 큐**를 이용하면 편리합니다. 우선 순위 큐엔 $y$좌표와 힘과 색깔 종류도 함께 저장해서 모든 색이 갖춰지는지 검사합니다.

**스위핑(Sweeping)** 은 말 그대로 '빗자루로 바닥을 쓸 듯이' 특정 방향(보통 왼쪽에서 오른쪽)으로 공간을 지나가며 문제를 해결하는 기법입니다.

이와 같은 방식 덕분에 가로 길이는 신경 쓸 필요 없이 가로에서 점이 추가되고 모든 색이 갖춰질 때마다 세로의 높이만 잘라주면 됩니다.

```python
import sys
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

import heapq

def main():
    n, k = map(int, input().split())
    cnt = [0]*(k+1)
    g = [tuple(map(int, input().split())) for _ in range(n)]
    g.sort()
    ans = cur = 0
    maxh = 123456789
    max_hq = []
    for i in range(n):
        x, y, p, c = g[i]
        heapq.heappush(max_hq, (-y, p, c))
        cur += p
        if not cnt[c]: cnt[0] += 1
        cnt[c] += 1
        if i == n-1 or g[i+1][0] != x:
            while max_hq:
                yy = -max_hq[0][0]
                if cnt[0] != k and yy <= maxh: break
                _, pp, cc = heapq.heappop(max_hq)
                cur -= pp
                cnt[cc] -= 1
                if not cnt[cc]: cnt[0] -= 1
                maxh = min(maxh, yy-1)
            ans = max(ans, cur)    
    print(ans)
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, k; cin >> n >> k;
    priority_queue<tuple<int, ll, int>> pq;
    vector<int> cnt(k+1, 0);
    vector<tuple<int, int, ll, int>> g;
    g.reserve(n);
    for(int i = 0; i < n; i++){
        int x, y, c; ll p; cin >> x >> y >> p >> c;
        g.push_back({x, y, p, c});
    }
    sort(g.begin(), g.end());
    ll ans, cur; ans = cur = 0;
    int maxh = 123456789;
    for(int i = 0; i < n; i++){
        auto [x, y, p, c] = g[i];
        pq.push({y, p, c});
        cur += p;
        if(!cnt[c]) cnt[0]++;
        cnt[c]++;
        if(i == n-1 || get<0>(g[i+1]) != x){
            while(pq.size()){
                auto [yy, pp, cc] = pq.top();
                if(cnt[0] != k && yy <= maxh) break;
                pq.pop();
                cur -= pp;
                cnt[cc]--;
                if(!cnt[cc]) cnt[0]--;
                maxh = min(maxh, yy-1);
            }
            ans = max(ans, cur);
        }
    }
    cout << ans;
    return 0;
}
```
