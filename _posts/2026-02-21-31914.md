## **풀이**
### **접근**
모든 직사각형은 $(0,0)$ 점에 고정되어 있습니다.

직사각형이 최대한 많은 점을 포함할수록 문제에서 요구하는 최댓값은 증가합니다. 그러므로 각 점의 힘보다 직사각형이 얼마나 많은 **점의 개수**를 포함하느냐가 관건입니다. 그러나 문제의 조건에서 직사각형에 **모든 색**의 점이 포함되어선 안 됩니다.

직사각형을 가로든 세로든 한쪽 방향으로 쭉 늘려봅시다.

예를 들어, 원점을 기준으로 세로 방향으로 무한히 긴 직사각형을 하나를 만듭시다. 그리고 이 직사각형을 가로 방향으로 늘려가는 겁니다. 늘려가면서 만나는 점의 색깔의 개수가 $k$가 다 채워지는지 확인을 해 가는 겁니다. 만약 색깔 개수가 다 채워진다면 세로 높이를 한 칸씩 줄여나가면서 세로 높이에 포함된 점들을 제외해 주는 겁니다.

다음 가로 방향으로 늘려갈 때마다 직사각형이 포함하고 있는 점의 개수의 최댓값을 갱신해 주고 이걸 반복하며 모든 점을 검사하면 최종 최댓값을 구할 수 있습니다.

이는 반대로 가로로 긴 직사각형을 만들어 세로 방향으로 늘려가도 동일한 풀이가 됩니다.

### **정렬**
가로 방향으로 직사각형을 늘려가면서 점을 추가해 봅시다. 이를 위해서는 $x좌표\to y좌표$ 기준으로 **오름차순 정렬**을 해주면 됩니다.

### **우선순위 큐**
가로 방향에서 점을 늘려가다가 모든 색이 포함될 시 세로 방향의 **가장 위**의 점부터 직사각형을 잘라나가는 겁니다. 세로 방향의 값이 가장 큰 것부터 잘라내서 제외되는 점의 개수를 최소화합시다. 가장 큰 값부터 찾아내기 위해서 **우선순위 큐**를 이용하면 편리합니다. 우선순위 큐엔 $y$좌표와 점의 개수와 색깔 종류도 함께 저장해서 제외되는 점의 정보도 제거해 줍니다.

모든 색의 개수를 검사하고 다음 가로 방향으로 갈 때 점의 개수를 최댓값과 비교 후 갱신해 줍니다. 이렇게 모든 점을 검사해 주면 됩니다.

### **스와핑**
위와 같이 방법으로 모든 점을 검사하면 2차원 좌표평면의 문제를 가로 길이는 굳이 신경 쓸 필요 없이 가로를 늘려가면서 색의 개수와 세로 높이만 조절하는 1차원적 문제로 환원시킬 수 있게 됩니다. 이를 **스위핑(Sweeping)** 방법이라 부릅니다.

**스위핑(Sweeping)** 은 말 그대로 **빗자루로 바닥을 쓸 듯이** 특정 방향(보통 왼쪽에서 오른쪽)으로 공간을 지나가며 문제를 해결하는 기법입니다.

```python
import sys
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

import heapq

def main():
    n, k = map(int, input().split())
    cnt = [0]*(k+1)
    g = [tuple(map(int, input().split())) for _ in range(n)]
    g.sort()
    ans = cur = 0
    maxh = 123456789
    max_hq = []
    for i in range(n):
        x, y, p, c = g[i]
        heapq.heappush(max_hq, (-y, p, c))
        cur += p
        if not cnt[c]: cnt[0] += 1
        cnt[c] += 1
        if i == n-1 or g[i+1][0] != x:
            while max_hq:
                yy = -max_hq[0][0]
                if cnt[0] != k and yy <= maxh: break
                _, pp, cc = heapq.heappop(max_hq)
                cur -= pp
                cnt[cc] -= 1
                if not cnt[cc]: cnt[0] -= 1
                maxh = min(maxh, yy-1)
            ans = max(ans, cur)    
    print(ans)
    return 0
if __name__ == '__main__':
    sys.exit(main())
```

```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, k; cin >> n >> k;
    priority_queue<tuple<int, ll, int>> pq;
    vector<int> cnt(k+1, 0);
    vector<tuple<int, int, ll, int>> g;
    g.reserve(n);
    for(int i = 0; i < n; i++){
        int x, y, c; ll p; cin >> x >> y >> p >> c;
        g.push_back({x, y, p, c});
    }
    sort(g.begin(), g.end());
    ll ans, cur; ans = cur = 0;
    int maxh = 123456789;
    for(int i = 0; i < n; i++){
        auto [x, y, p, c] = g[i];
        pq.push({y, p, c});
        cur += p;
        if(!cnt[c]) cnt[0]++;
        cnt[c]++;
        if(i == n-1 || get<0>(g[i+1]) != x){
            while(pq.size()){
                auto [yy, pp, cc] = pq.top();
                if(cnt[0] != k && yy <= maxh) break;
                pq.pop();
                cur -= pp;
                cnt[cc]--;
                if(!cnt[cc]) cnt[0]--;
                maxh = min(maxh, yy-1);
            }
            ans = max(ans, cur);
        }
    }
    cout << ans;
    return 0;
}
```
