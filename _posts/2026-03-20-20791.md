[문제 링크](https://www.acmicpc.net/problem/20791) 
## **풀이**
### **문제 요약**

$$M = \begin{bmatrix} 
x+a_1b_1 & a_1b_2 & \cdots & a_1b_N \\ 
a_2b_1 & x+a_2b_2 & \cdots & a_2b_N \\ 
\vdots & \vdots & \ddots & \vdots \\
a_Nb_1 & a_Nb_2 & \cdots & x+a_Nb_N
\end{bmatrix}$$

위와 같이 구성된 행렬 $M$의 **행렬식** 값에 $10^9+7$로 나눈 나머지 값을 구해야 합니다.

### **행렬식 공식**

$$\det(M) = x^n + x^{n-1} \sum_{i=1}^{n} a_i b_i$$

행렬식 공식은 위와 같습니다. 위 공식을 이용해서 행렬 $M$의 행렬식을 그대로 구해도 됩니다.

그러나, **가우스 소거법**을 행렬 $M$에 적용하면 계산이 좀 더 간단해집니다. 가우스 소거법은 한 행에 다른 행의 상수배를 곱해 더하거나 빼도 행렬식 값은 같아진다는 원리입니다. 따라서, 1행에 $\frac{a_i}{a_1}$를 곱한 값을 모든 행에서 빼주면, 다음과 같이 행렬 $M$을 바꿀 수 있습니다.

$$M = \begin{bmatrix} 
x+a_1b_1 & a_1b_2 & \cdots & a_1b_N \\ 
-\frac{a_2}{a_1}x & x & \cdots & 0 \\ 
\vdots & \vdots & \ddots & \vdots \\
-\frac{a_N}{a_1}x & 0 & \cdots & x
\end{bmatrix}$$

위의 기존 행렬의 행렬식과 가우스 소거법을 적용한 행렬의 행렬식의 값은 같습니다. 그럼 대각선을 중심으로 행렬 원소가 대부분 0으로 바뀐 것을 알 수 있습니다. 덕분에 행렬식 계산이 좀 더 간결해집니다. 여기서 행렬식 대각선의 곱을 빼줍니다. 

$(x+a_1b_1) \times x \times x \dots \times x = \mathbf{(x+a_1b_1)x^{n-1}}$에서 $\times (a_1 b_i) \times \left(-\frac{a_i}{a_1}x\right) \times x^{n-2} = \mathbf{a_i b_i x^{n-1}}$를 빼주면 $x^{n-1} \left( x + a_1b_1 + a_2b_2 + \dots + a_nb_n \right) = x^{n-1} \left( x + \sum_{i=1}^{n} a_i b_i \right)$과 같이 행렬식 공식을 얻을 수 있습니다.

실은 가우스 소거법은 행렬식 공식을 $x^{n-1}$로 묶어준 것과 다름없습니다. 

$$\det(M) = x^n + x^{n-1} \sum_{i=1}^{n} a_i b_i \Rightarrow x^{n-1}\times(x + \sum_{i=1}^{n} a_i b_i) $$

위 공식을 그대로 구현해 주면 됩니다.

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

MOD = 1_000_000_007

def main():
    while nx := list(map(int, input().split())):
        n, x = nx
        a = list(map(int, input().split()))
        b = list(map(int, input().split()))
        xx = pow(x, n-1, MOD)
        for i in range(n): x = (x+a[i]*b[i]%MOD)%MOD
        print(xx*x%MOD)
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

const ll MOD = 1'000'000'007;

ll pow(ll x, ll r){
    ll ret = 1;
    while(r){
        if(r&1) ret = ret*x%MOD;
        x = x*x%MOD;
        r >>= 1;
    }
    return ret;
}

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    ll n, x;
    while(cin >> n >> x){
        vector<ll> a(n), b(n); 
        for(int i = 0; i < n; i++) cin >> a[i];
        for(int i = 0; i < n; i++) cin >> b[i];
        ll xx = pow(x, n-1);
        for(int i = 0; i < n; i++) x = (x+a[i]*b[i]%MOD)%MOD;
        cout << xx*x%MOD << '\n';
    }
    return 0;
}
```
