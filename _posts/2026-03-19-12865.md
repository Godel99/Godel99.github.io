[문제 링크](https://www.acmicpc.net/problem/12865) 
## **풀이**
### **DP**
* $dp[i]$: 무게가 $w$일 때, 가질 수 있는 최대 가치

### **0/1-배낭**
물건을 넣을 건지 안 넣을 건지를 결정하는 0/1-배낭 문제입니다. **역순**으로 **현재 물건은 한 번만 다뤄서** 공간을 좀 더 최적화할 수 있습니다.

$$dp[i] = \max(dp[i], dp[i - W_i] + V_i)$$

무게 $k$부터 $w$까지 역순으로 위 식을 적용하면 배낭에 담을 수 있는 최대 가치를 구할 수 있습니다.

## **구현**
<details markdown="1">
<summary>코드</summary>

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    n, k = map(int, input().split())
    dp = [0]*(k+1)
    for _ in range(n):
        w, v = map(int, input().split())
        if w > k: continue
        for i in range(k, w-1, -1): 
            if dp[i] < dp[i-w]+v: dp[i] = dp[i-w]+v
    print(dp[k])
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, k; cin >> n >> k;
    vector<int> dp(k+1, 0);
    while(n--){
        int w, v; cin >> w >> v;
        if(w > k) continue;
        for(int i = k; i >= w; i--) dp[i] = max(dp[i], dp[i-w]+v);
    }
    cout << dp[k];
    return 0;
} 
```
