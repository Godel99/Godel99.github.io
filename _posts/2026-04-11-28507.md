[문제 링크](https://www.acmicpc.net/problem/28507) 
## **풀이**
$1$분부터 $N$분까지 $1$분마다 다음 생각 중 하나를 선택해 진행해야 합니다.

* 부정적 생각하기: 기분 $x$가 $x-1$이 됩니다.
* 모호한 생각하기: 기분 $x$가 $2\cdot(x+i-2)$가 됩니다.

처음 기분 $x=0$이고, $N$분 뒤에도 $x=0$이 되어야 합니다. 이때, 부정적 생각의 횟수를 최소화해야 합니다.

### **치환**
모호한 생각에 변수 $i$를 제거해주면 계산이 좀 더 수월해질 겁니다. 변수 $x$를 $y_i=x_i+2i$로 치환해 줍니다.

* 부정적 생각:
  * $x_{i} = x_{i-1} - 1$
  * $y_i = x_i + 2i = (x_{i-1} - 1) + 2i = (y_{i-1} - 2(i-1)) - 1 + 2i = y_{i-1} + 1$
  * 즉, $y \rightarrow y + 1$ (**수치가 1 증가**)
* 모호한 생각:
  * $x_{i} = 2(x_{i-1} + i - 2)$
  * $y_i = x_i + 2i = 2(x_{i-1} + i - 2) + 2i = 2x_{i-1} + 2i - 4 + 2i = 2x_{i-1} + 4i - 4 = 2(x_{i-1} + 2i - 2) = 2y_{i-1}$
  * 즉, $y \rightarrow y \times 2$ (**수치가 2배 증가**)

$i$와 상관없이 1분마다 연산이 $+1$ 또는 $\times 2$로 바뀐 것을 알 수 있습니다. 다음은 치환에 따른 시점 변화입니다.

* 시작 시점 ($i=0$): $x=0$이므로 $y_0 = 0 + 2(0) = 0$입니다.
* 종료 시점 ($i=n$): $x=0$이어야 하므로 $y_n = 0 + 2n = 2n$이 되어야 합니다.

치환을 통해 문제가 **$0$에서 시작해서 $N$번의 연산( $+1$ 또는 $\times 2$ )을 통해 정확히 $2N$을 만들고 이때 $+1$ 연산의 최소 횟수**를 구하는 문제로 간결해집니다.

### **이진수**
연산 $+1$ 또는 $\times 2$를 보면, 이진수를 만드는 데 특화된 연산임을 알 수 있습니다. 비트 1을 만들고 이를 오른쪽으로 한 칸 이동시키는 연산입니다. 따라서, $2N$을 이진수로 나타내면 비트 1의 개수가 바로 $+1$연산 횟수의 최솟값과 같다는 것은 자명합니다. 왜냐면 $\times 2$연산은 비트 오른쪽에 0을 추가만 하기 때문입니다.

이제 $2N$을 이진수로 바꾸고, $2N\rightarrow0$하기 위해 오른쪽 비트부터 **역순**으로 연산을 판별해 주면 됩니다.

## **구현**

```python
import sys
input = lambda: sys.stdin.readline().rstrip()
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)

def main():
    t = n = int(input()); n <<= 1
    ans = []
    while n:
        if n&1: ans.append(t); t -= 1
        t -= 1
        n >>= 1
    print(len(ans))
    print(*reversed(ans))
    return
if __name__ == "__main__":
    main()
```
```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    ll t, n; cin >> n; t = n; n <<= 1;
    stack<ll> ans;
    while(n){
        if(n&1) ans.push(t--);
        t--;
        n >>= 1;
    }
    cout << ans.size() << '\n';
    while(ans.size()){cout << ans.top() << ' '; ans.pop();}
    return 0;
}
```
