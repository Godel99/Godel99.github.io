[문제 링크](https://www.acmicpc.net/problem/1353) 
## **풀이**
음이 아닌 실수들의 합 $S$과 곱 $P$이 주어졌을 때, 합과 곱을 만족하는 실수의 최소 개수를 구해야 합니다.

합과 곱이 같다면 최소 개수는 1개가 자명합니다.

### **산술·기하 평균 부등식**
양수 $a_1, a_2, \dots, a_n$ 대해서 산술·기하 평균 부등식은 아래와 같습니다.

$$\frac{a_1 + a_2 + \dots + a_n}{n} \ge \sqrt[n]{a_1 \cdot a_2 \cdot \dots \cdot a_n}$$

이를 이 문제에 적용하면, 

$$P \le \left(\frac{S}{n}\right)^n$$

위와 같은 식으로 나타낼 수 있습니다. 여기서 합 $S$를 $n$으로 동일하게 나눈 값들을 원소라고 하면 모든 원소는 같아지는데, 그 때 모든 원소들의 곱이 **최대**가 됩니다. 만약 $P_{max}(n) = \left(\frac{S}{n}\right)^n$에서 주어진 $P$에 대해 $P_{max}(n)<P$라면 $n$으로 나타낼 수 있는 최대 곱이 주어진 $P$보다 작으므로 이를 만족하려면 $S$가 고정 값이므로 $n$을 증가시켜야 합니다. 그럼 어느 순간 $n$이 $P_{max}(n)\geq P$를 만족한다면, $n$은 최대 곱에서 만족하는 $P$ 찾았으므로 $n$이 **최솟값**이 됩니다.

즉, $n$이 구하고자 하는 실수의 최소 개수가 됩니다.

### **미분**
<p align="center"/><img src="/assets/img/posts/1353.png" alt="S/e" width="700">

$P$는 고정 값이므로 $\left(\frac{S}{n}\right)^n$을 미분하면, $n=\frac{S}{e}$가 됩니다. 이 값을 가지고 이분 탐색을 해도 답을 구할 수 있지만, $P \le \left(\frac{S}{n}\right)^n$에서 $n$을 1씩 증가시켜가며 $P$를 만족하는 최솟값 $n$을 찾는 게 구현이 좀 더 간단합니다.

왜냐면 $P$의 최대가 $10^9$이지만, $n$이 $20\sim30$범위만 되어도 $\left(\frac{S}{n}\right)^n$가 가볍게 $10^9$ 돌파해 버립니다. 즉, 30번 이내로 최솟값 $n$을 찾을 수 있는 겁니다.

## **구현**
<details markdown="1">
<summary>코드</summary>

```python
import sys 
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

def main():
    s, p = map(int, input().split())
    if s == p: print(1); return
    n, d = 2, 0
    while True:
        m = pow(s/n, n)
        if m >= p: print(n); return
        if m < d: print(-1); return
        d = m
        n += 1
if __name__ == '__main__':
    main()
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int s, p, n; cin >> s >> p; n = 2;
    if(s == p) return !(cout << 1);
    double d = 0;
    while(true){
        double m = pow(1.0*s/n, n);
        if(m >= p) return !(cout << n);
        if(m < d) return !(cout << -1);
        d = m;
        n++;
    }
    return 0;
}
```
