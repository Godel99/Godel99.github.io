[문제 링크](https://www.acmicpc.net/problem/17626) 
## **풀이**
### **브루트포스 + 수학적 접근**
$DP$로 접근해도 충분히 해결이 가능합니다. 그러나 문제에서 모든 자연수는 **넷 혹은 그 이하의 제곱수의 합**으로 표현할 수 있다는 힌트를 줬으니 이 수학적 정리를 기반하여 해결해 봅시다.

일종에 **브루트포스** 접근 방법인데 넷 혹은 그 이하의 제곱수를 직접 찾아주는 겁니다. 제곱수의 개수가 각각 순서대로 1개, 2개, 3개, 4개일 경우를 모두 직접 찾아서 찾은 즉시 출력을 해주면 됩니다.

1. 1개인 경우: $n$이 완전 제곱수인지 확인합니다.
2. 2개인 경우: $n-i^2$이 어떤 수 $j^2$이 되는지 확인합니다.
3. 3개인 경우: $n-i^2-j^2$이 어떤 수 $k^2$이 되는지 확인합니다.
4. 4개인 경우: 위 경우들이 모두 해당되지 않으면 답은 4개입니다.

## **구현**

```python
import sys
print = lambda *args, sep=" ", end="\n": sys.stdout.write(sep.join(map(str, args)) + end)
input = lambda: sys.stdin.readline().rstrip('\r\n')

from math import sqrt

def main():
    n = int(input())
    if n == int(sqrt(n))**2: return int(not print(1))
    for i in range(1, int(sqrt(n))+1):
        if n-i*i == int(sqrt(n-i*i))**2: return int(not print(2))
    for i in range(1, int(sqrt(n) )+1):
        for j in range(1, int(sqrt(n-i*i))+1):
            if n-i*i-j*j == int(sqrt(n-i*i-j*j))**2: return int(not print(3))
    print(4)
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

bool is_squ(int n){
    int t = (int)sqrt(n);
    return n == t*t;
}

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n; cin >> n;
    if(is_squ(n)) return !(cout << 1);
    for(int i = 1; i*i <= n; i++){
        if(is_squ(n-i*i)) return !(cout << 2);
    }
    for(int i = 1; i*i <= n; i++){
        for(int j = 1; i*i+j*j <= n; j++){
            if(is_squ(n-i*i-j*j)) return !(cout << 3);
        }
    }
    cout << 4;
    return 0;
}
```
