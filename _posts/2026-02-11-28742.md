[문제 링크](https://www.acmicpc.net/problem/28742) 
## **풀이**
### 문제 요약
1. 수열에 값 $v$를 추가합니다.
2. 수열에서 $p$번째 원소를 제거합니다.
3. 수열의 모든 원소에 $e$를 $XOR$합니다.

각 질의 후 수열의 원소의 합을 구하세요.

### 접근
문제가 요구한 대로 수열을 배열로 만들고 추가하거나 제거, 모든 원소에 $XOR$ 연산을 해도 되지만, 그럼 $1\leq n,\ q \leq 100000$이므로 질의 3번에서 시간 초과가 날 수 있습니다.

### 비트 단위 
수열의 원소를 **비트 단위**로 바꿔서 비트가 1인 원소의 개수로 바꿔줍니다. 즉, 원소의 값이 이제 1인 비트의 개수로 표현될 수 있습니다. 이러면 3번 질의가 간단해집니다. 3번 질의에서 모든 원소에 $XOR$를 할 필요 없이 $XOR$ **오프셋 변수**를 따로 관리해 질의 후 합을 구할 때만 적용해 줍니다.

### XOR 오프셋
초기 $XOR$ 오프셋($e$)이 0이므로 오프셋 적용 없이 비트 단위 배열 $cnt[32]$에 저장해 줍니다. 1번 질의를 할 때마다 $XOR$ 오프셋($e$)을 적용해 비트가 1인 것은 0으로, 0은 1로 바꿔서 $cnt[32]$에 저장합니다.

2번 질의는 원소를 제거하므로 오프셋 적용 없이 $cnt[32]$ 값만 빼주면 됩니다.

질의 후 합을 출력할 때, $XOR$ 오프셋($e$)으로 바뀐 비트를 원상복구해 줘야 합니다. **$n-cnt[bit]$**가 오프셋 비트를 원래대로 돌려줍니다. 왜 $n$에서 빼주냐면 원래 비트로 돌아가느냐면 $n$의 비트엔 1인 비트 + 0인 비트가 함께 저장되어 있으므로 그 값을 빼줘 원래 비트로 되돌아가는 것입니다.

```python
import sys
def print(*args, sep=" ", end="\n"): return sys.stdout.write(sep.join(map(str, args)) + end)
def input(): return sys.stdin.readline().rstrip()

def main():
    n, q = map(int, input().split()); idx = n
    a = [0]*(n+q+1)
    cnt = [0]*32
    e = 0
    for i, v in enumerate(map(int, input().split())): 
        a[i+1] = v
        for bit in range(32):
            if a[i+1]&(1<<bit): cnt[bit] += 1
    for _ in range(q):
        query = tuple(map(int, input().split()))
        t = query[0]
        if t == 1:
            idx += 1; n += 1
            v = query[1]^e
            a[idx] = v
            for bit in range(32):
                if a[idx]&(1<<bit): cnt[bit] += 1
        elif t == 2:
            p = query[1]; n -= 1
            for bit in range(32):
                if a[p]&(1<<bit): cnt[bit] -= 1
        else:
            e ^= query[1]
        ans = 0
        for bit in range(32):
            if e&(1<<bit): ans += (n-cnt[bit])<<bit
            else: ans += cnt[bit]<<bit
        print(ans)
    return 0
if __name__ == '__main__':
    sys.exit(main())
```
```c++
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

int main(){
    cin.tie(0); cout.tie(0); ios::sync_with_stdio(false);
    int n, q, idx; cin >> n >> q; idx = n;
    vector<int> a(n+q+1, 0);
    ll cnt[32] = {}, e = 0;
    for(int i = 1; i <= n; i++){
        cin >> a[i];
        for(int bit = 0; bit < 32; bit++) if(a[i]&(1<<bit)) cnt[bit]++;
    }
    while(q--){
        int query; cin >> query;
        if(query == 1){
            int v; cin >> v; a[++idx] = v^e; n++;
            for(int bit = 0; bit < 32; bit++) if(a[idx]&(1<<bit)) cnt[bit]++;
        }
        else if(query == 2){
            int p; cin >> p; n--;
            for(int bit = 0; bit < 32; bit++) if(a[p]&(1<<bit)) cnt[bit]--;
        }
        else {
            int t; cin >> t; e ^= t;
        }
        ll ans = 0;
        for(int bit = 0; bit < 32; bit++){
            if(e&(1LL<<bit)) ans += (n-cnt[bit])<<bit;
            else ans += cnt[bit]<<bit;
        }
        cout << ans << '\n';
    }
    return 0;
}
```
### 시간 및 공간 복잡도
* 시간복잡도: $\mathcal{O}((N + Q) \times 32)$
* 공간복잡도: $\mathcal{O}(N + Q + 32)$
